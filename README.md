## 중요한 운영 경계

- 신규 가입은 활성화됐으며 비밀번호 원문 대신 PBKDF2-SHA-256 해시를 저장합니다. 약관 공개 상태는 법률 전문가 검토 완료를 뜻하지 않습니다. 기존 이전회원 282계정은 보류 상태입니다.
- 기존 이니시스 MID·키를 사용하는 PC/모바일 카드 요청은 Cloudflare 운영에 연결됐습니다. 실카드 승인·취소 시험은 아직 수행하지 않았습니다. 자동 INIAPI 환불은 꺼져 있고, 이니시스 관리자에서 실제 취소한 뒤 홈페이지에 증빙을 반영합니다.
- 운영에서는 테스트 역할 전환을 차단하고 기존 자료·관리자 콘텐츠를 제공합니다. 개발용 mock·정적 샘플을 운영 고객 데이터나 실제 승인 증거로 사용하지 않습니다.
- 후보자의 실명·연락처·근무기관 이력은 병원별 동의와 서버 권한 검증 후에만 제공해야 합니다.
