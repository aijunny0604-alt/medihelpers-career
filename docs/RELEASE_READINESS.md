# 정식 출시 준비 체크리스트

기준일: 2026-08-02

## 코드로 완료된 항목

- 자체 이메일·비밀번호 회원가입·로그인, D1 계정·세션, 다른 PC 로그인
- 의료인 이력서 등록·공개 동의, 병원 광고 신청, 관리자 검수·게시
- 병원용 인재 열람권 가상 결제와 권한 발급(QA 전용)
- D1 스키마 런타임 자동 생성, R2 일일 백업·보존 정리·감사 기록
- 로그아웃, 역할별 서버 권한 검사, 개인정보 마스킹, 보안 헤더
- 카카오 주소 검색 인라인 모달, 반응형 화면, 검색엔진 기본 파일

## 정식 출시 전에 반드시 외부에서 확정할 항목

- `medihelpers.co.kr`를 Cloudflare 운영 배포에 연결하고 HTTPS·www/apex 정책 확정
- 이니시스 운영 MID·서명키·웹훅 계약 완료 후 Cloudflare Workers에서 실결제 통합 테스트
- 이용약관·개인정보처리방침·환불정책·직업정보제공/유료직업소개업 관련 법무 검토
- 의료인 면허·병원 사업자 및 담당자 재직 확인의 실제 운영 절차와 관리자 책임자 확정
- Resend/Solapi 등 이메일·문자 공급자 키와 발신자 승인, 장애 대응 연락망 설정
- 실제 운영 공고·인재 데이터 검수 및 정적 데모 데이터의 운영 DB 이전/삭제 기준 확정

## 출시 전 환경 설정

- `TEST_ACCOUNT_SWITCH_ENABLED=false`
- `ADMIN_EMAILS`, `ACCOUNT_HASH_SECRET`, 가입 게이트 값을 운영값으로 재확인
- Sites에는 결제 비밀키를 넣지 않으며 실결제는 Cloudflare에서만 활성화
- 기존 Sites `.openai/hosting.json`의 프로젝트 ID와 D1/R2 바인딩은 변경하지 않음

## 최종 검증

- `npm test`와 대상별 프로덕션 빌드 통과
- 회원가입→로그인→이력서/광고 등록→관리자 검수 흐름을 새 PC/브라우저에서 실행
- 결제 성공·실패·취소·중복 콜백·환불과 권한 회수 테스트
- `/robots.txt`, `/sitemap.xml`, canonical, 공유 썸네일, 네이버 서치어드바이저 소유권 확인
- 백업 생성·다운로드·복구 리허설과 최근 성공 시각 확인
