전환 초기에는 랭크업을 보존한다. 이후 완전한 자료·복구 환경·운영 변경분 처리 방법을 확보하고 별도 해지를 결정한다. **랭크업 호스팅 해지 후에는 DNS만 되돌려 즉시 복구할 수 있다고 보장할 수 없다.** 호스팅이 남아 있어도 새 사이트에 생긴 회원·결제·환불 기록은 DNS 복구만으로 옮겨지지 않는다.
