# 일반 회원 화면 내부 코드 숨김

## 변경 사항

- 일반·의료인·병원 회원의 문의 목록과 문의 상세에서 `SEEK-*`, `INQ-*` 같은 내부 접수번호를 표시하지 않습니다.
- 내부 접수번호 대신 관련 채용공고명, 맞춤 헤드헌팅, 상담 접수 등 사람이 이해하기 쉬운 내용을 표시합니다.
- 추천 후보 카드에서도 내부 후보 코드를 숨기고 최근 업데이트 날짜만 표시합니다.
- 관리자 권한 화면에서는 운영 추적과 감사에 필요한 내부 접수번호를 계속 확인할 수 있습니다.
- 내부 코드는 화면에서만 숨기며 라우팅, API 요청, 데이터 연결에는 그대로 사용합니다.

## 확인 항목

- 일반 회원 문의 목록에 내부 코드가 노출되지 않는지 확인
- 병원 회원 문의 상세 제목 아래 내부 코드가 노출되지 않는지 확인
- 문의 상세의 `관련 내용`에 공고명 또는 문의 종류가 표시되는지 확인
- 관리자 권한에서는 `내부 접수번호`가 표시되는지 확인
- 추천 후보 카드에 후보 내부 코드가 노출되지 않는지 확인
