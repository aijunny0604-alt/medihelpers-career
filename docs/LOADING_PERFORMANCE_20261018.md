## 수정 범위

1. 알려진 React 화면의 일반 내부 링크는 기존 라우터로 이동한다. 메일·전화·외부 URL·새 탭·다운로드·해시 링크·기존 랭크업·PG 콜백은 기존 브라우저 동작을 유지한다. 링크를 가리키거나 키보드로 선택하면 해당 화면의 코드만 준비한다. 개인정보나 결제 자료는 미리 요청하지 않는다.
2. 마이페이지에서는 마이페이지만 알림을 읽고 헤더에는 개수를 전달한다. 다른 화면에서는 헤더가 조회한다. 숨겨진 탭은 중단하고 복귀 시 갱신하며, 대기 요청 중에는 새 조회를 겹치지 않는다. 계정 변경과 화면 이탈 시 늦은 결과를 폐기한다.
3. 계정·알림 조회에서 불필요한 구직글 만료 처리와 광고/결제 조회를 제외한다. 계정 프로필과 기존 접속 이력 저장을 묶고, 공고 조회는 인증 결과를 재사용하며 독립 조회를 묶는다. 게시판과 전체 마이페이지의 만료 처리는 유지한다.
4. 로그인 성공·로그아웃·비밀번호 변경의 세션 초기화와 서버 권한 검사는 유지한다. 회원 자료의 브라우저 영구 캐시를 추가하지 않았다. 최초 접속, 새 화면 코드와 최신 개인 정보 조회에는 실제 대기가 남는다.
