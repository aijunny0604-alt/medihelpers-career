## 사용할 수 있는 접근 방식

전환 후 옛 서버 관리자 작업이 필요하면 **지정된 관리 PC**에서만 기존 두 호스트를 `121.254.171.115`로 해석하도록 임시 hosts 매핑한다. IP 주소 자체로 로그인하면 가상호스트·인증서가 맞지 않을 수 있으므로 원래 HTTPS 도메인을 유지한다. 공개 DNS를 되돌리지 않고 옛 사이트를 조회할 방법이다.

예상 Windows hosts 항목(현재 미적용):

```text
121.254.171.115 medihelpers.co.kr www.medihelpers.co.kr
```

적용 전 hosts 원본 백업, 관련 기존 항목 충돌 확인, 변경 범위 기록이 필요하다. 검수 후 추가한 줄만 제거하고 DNS 캐시·브라우저 연결을 갱신한다. 이 PC에서는 새 정식 사이트 검수가 불가능하므로 새 사이트 검수는 매핑하지 않은 별도 환경에서 수행한다. 기존/신규 세션 혼동을 피하도록 별도 브라우저 프로필을 사용한다. 현재 PC에 실제 적용하지 않았다.

## 검증 한계

- 원본 HTTPS와 로그인 폼 도달을 검증했으며, 실제 전환 후 관리자 로그인·저장·결제 처리는 미검증이다.
- 기존 호스팅과 원래 도메인의 인증서가 계속 유효해야 한다. 서버 IP/인증서가 바뀌면 재검증한다.
- 관리 PC 매핑은 PG 서버나 고객 브라우저에 적용되지 않는다. **지연 결제 콜백 수신을 해결하지 않으며**, 기존 진행 중 거래의 확인·처리 조건을 대체하지 않는다.
- 전체 랭크업 DB·첨부 백업, 신규 변경분 역이전 완료의 근거가 아니다.
