# 구직글 작성자 무료 열람

## 정책

- 로그인한 의료인이 직접 작성한 구직글은 열람권 없이 상세 내용을 볼 수 있습니다.
- 서버가 현재 로그인 계정 ID와 이력서의 `account_id`를 비교해 소유자를 판정합니다.
- 작성자 무료 열람은 병원 열람권이나 팩 크레딧을 사용하지 않습니다.
- 다른 의료인의 구직글과 병원 회원의 열람은 기존 열람권·동의·공개 범위 정책을 유지합니다.
- 관리자 권한과 열람 감사 정책도 기존대로 유지합니다.

## 화면

- 작성자 본인의 목록 행에는 `내 글 · 무료`가 표시됩니다.
- 상세 화면에는 `작성자 무료 열람`과 `내 구직글 수정` 버튼이 표시됩니다.
- 소유권을 확인할 수 없는 샘플 글은 무료 열람으로 처리하지 않습니다.

## 보존 사항

- 기존 OpenAI Sites 프로젝트를 유지합니다.
- D1 `DB`, R2 `BACKUPS` 바인딩과 기존 스키마를 변경하지 않습니다.
