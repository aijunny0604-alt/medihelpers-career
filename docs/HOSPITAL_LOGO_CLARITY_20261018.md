- 홈과 병원 채용란의 로고형 메인 광고를 `로고 → 병원명` 세로 배치로 변경했다. 로고는 가로 공간을 사용하고 병원명은 별도 HTML 텍스트로 표시한다.
- 확인한 원본 4개는 파일 해시별로 흰 여백의 표시 범위만 조정한다. 원본 이미지 파일·픽셀·종횡비는 변경하지 않으며 실제 로고 영역을 잘라내지 않는다. 이미지 전체를 원본 픽셀 크기보다 확대하지 않는다.
- 다른 병원 로고는 임의로 자르지 않고 원본 비율에 맞춰 `scale-down`한다. 로고형 카드의 기울임·확대 애니메이션을 제거한다.
- 로고 파일을 읽지 못하면 병원 아이콘과 병원명을 유지한다. 깨진 이미지 표시로 카드가 무너지지 않는다.
- 광고 등록 시 작은 이미지에는 실제 가로·세로 픽셀 수, 권장 1500×500px, 그대로 등록할 수 있다는 안내를 제공한다. 이미지 교체 시 안내를 갱신하고, 형식·용량 오류 시 이전 미리보기도 정리한다.
- 이미 등록된 전체 배너 이미지, 공고 내용·광고 기간·결제/회원/관리자 권한, DB·DNS·랭크업은 변경하지 않는다. 고해상도처럼 보이는 데모 병원 로고로 실제 병원 상표를 대체하지 않았다.
