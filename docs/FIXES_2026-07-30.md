# 기능 오류 수정 및 검증 기록 (2026-07-30)

## 이번 수정

- OpenAI Sites 업로드 API가 `UPLOADS` 바인딩이 없을 때 기존 `BACKUPS` R2를 사용하도록 보완했습니다.
  - Cloudflare 배포에서는 전용 `UPLOADS` 바인딩을 우선 사용합니다.
  - Sites에서는 `BACKUPS/hospitals/` 경로를 사용합니다.
- 메인 화면과 채용정보 화면의 공고 카드를 클릭하면 페이지를 이동하지 않고 상세 모달을 열도록 통일했습니다.
- 채용정보의 프리미엄 공고를 `PremiumAdCarousel`로 연결해 등급을 유지한 자동 순환 노출을 적용했습니다.
- `/medical-staff/jobs/:id` 직접 접근에도 의료인 로그인 게이트를 적용했습니다.
- 모바일 햄버거 메뉴의 최소 터치 영역을 44×44px로 보장했습니다.
- 프리미엄 순환 도구의 깨진 한글 문구와 접근성 라벨을 정상화했습니다.

## 검증

- Node 테스트: 70/70 통과
- 프로덕션 빌드: 통과
- 실제 Edge 자동검증:
  - 홈 공고 클릭 시 URL 유지 + 상세 모달 열림
  - 채용정보 공고 클릭 시 URL 유지 + 상세 모달 열림
  - 프리미엄 순환 영역과 도구막대 렌더링
  - 모바일 메뉴 44×44px
  - 비로그인 상태에서 의료인 전용 상세 경로 차단

## 현재 의도적으로 테스트 상태인 항목

- 실제 PG 결제와 외부 본인인증은 운영 키를 연결하기 전까지 테스트 모드로 유지합니다.
- 이메일·문자 알림은 Resend/Solapi 운영 환경변수를 연결하기 전까지 실제 발송하지 않습니다.
