# 랭크업 독립 준비 — 2026-10-08

## 운영 방향

사용자 목표는 랭크업 관리비 없이 Cloudflare에서 독립 운영하는 것이다. 랭크업 결제 중계·IP 추가는 진행하지 않는다. 기존 호스팅은 자료 이전·복원 검증 전까지 보존하며, 해지하지 않았다. 현재 권한 범위는 정식 도메인 전환 직전까지다.

## 이번 변경

- 기존 공개 광고에서 수집·보존한 이미지 91개(5,057,926바이트)를 `public/legacy-media/`에 해시 파일명으로 포함했다. 원래 URL·회원 정보·이전 매핑은 공개 폴더에 넣지 않았다.
- `scripts/legacy-media-manifest.json`은 경로·크기·종류·SHA256만 기록한다.
- `scripts/audit-legacy-media.mjs`는 원본 파일과 Cloudflare 빌드 파일, Worker를 통한 응답 바이트를 대조한다. 파일 기반 ASSETS 대역을 사용한 로컬 검사이며 실제 Cloudflare 업로드 검증은 아니다.
- 이미지 91개 모두 일치, 검사 중 랭크업 네트워크 요청 0건. 공고 127건은 계속 비공개 초안이며 이미지의 배너/갤러리 배치 매핑과 공개 승인 작업은 별도로 남는다. 보존 이미지가 포함됐다는 이유로 광고 권리나 회원을 활성화하지 않았다.
- 10월 6일 저장 DB 스냅샷에서 기존 호스트 URL은 공고 migration 메타데이터에만 존재했다. 이것은 전체 DB·첨부 백업의 완전성이나 최신 운영 데이터 검증이 아니다.

## 결제 및 전환 잔여

[이니시스 취소 규격](https://manual.inicis.com/pay/cancel.html)의 요청 서버 IP 필드는 필수다. [방화벽 안내](https://www.inicis.com/blog/archives/121212)는 가맹점 IP 별도 등록이 불필요하다고 설명하지만, Workers에서 해당 필드에 넣을 값을 확정해 주지는 않는다. 고정 IP가 무조건 필수라는 의미로 확대하지 않는다.

Cloudflare 무료 직접 연동의 IP 처리 방식은 미확정이다. 독립 결제 서버 대안은 [AWS Lightsail 공개 IPv4 요금](https://aws.amazon.com/lightsail/pricing/) 기준 월 5달러부터이며 세금·초과 사용료가 별도일 수 있다. 사용자 비용 답변은 대기 중이고 계정 생성·유료 자원 생성은 하지 않았다. 기존 MID의 외부 호스팅 사용 조건, 실제 승인·취소·대사, 실제 역할 로그인, 최신 데이터와 복구 검증도 남아 있다.

## 배포 구분

이번 변경은 소스 후보다. Worker 재배포·DNS 변경·랭크업 설정·PG 키 변경 없음. 마지막 확인된 앱 82b1201/Worker 2b96835c 유지; 새 역할 로그인 검수 미완료. 미배포 후보에 포함된 이전 인증 변경 때문에 실제 역할 검증 없이 정식 전환하지 않는다.
