# 구직 인재 독립 상세 페이지 전환

## 변경 내용

- 의료인 구인구직 목록에서 인재 카드를 선택하면 모달이 아니라 `/medical-staff/talents/{id}` 독립 상세 페이지로 이동합니다.
- 상세 페이지에는 기존 핵심 조건, 상담 확인 범위, 열람권에 따른 연락처·이력서 정보를 그대로 유지합니다.
- 닫기 버튼 대신 구인구직 목록으로 돌아가는 명확한 링크를 제공합니다.
- 화면과 샘플 데이터에 있던 `헤드헌터 인증` 배지·설명·플래그를 제거했습니다.

## 유지 범위

- 병원회원의 인재 열람권과 의료인의 연락처 공개 동의 정책은 변경하지 않았습니다.
- 맞춤 헤드헌팅 상담·문의 기능은 유지하며, 별도의 인증 등급처럼 보이는 표현만 제거했습니다.
- Sites `project_id`, D1 `DB`, R2 `BACKUPS` 바인딩과 데이터베이스 스키마는 변경하지 않았습니다.

## 검증

- 독립 경로·목록 복귀 동선과 인증 표현 제거를 자동 회귀 테스트로 고정했습니다.
- 전체 Node 자동 테스트, 프로덕션 빌드, 생성 Worker 문법 검사와 diff 검사를 통과해야 배포합니다.
