## 데이터와 권한

`0017_job_post_contacts.sql`은 job_seeker_posts에 contact_phone, additional_contact_phone 두 열을 추가한다. 기존 글은 빈 값이며 원본 이력서 번호로 표시하는 호환 경로를 유지한다. 새 연락처는 본인 구직글 API에서만 수정할 수 있고 공개 목록에는 포함하지 않는다. 이력서 상세는 기존 소유자/관리자/열람권 검증 후 연락처 공개 설정을 적용한다. 기존 번호를 다른 사람에게 공개하는 자동 마이그레이션은 없다.

동의 안내 버전은 v1.3-2026-09-27로 변경했다. 연락처 공개 항목에 구직글 기본/추가 번호를 명시한다. 과거 동의 스냅샷은 고치지 않는다. 구 화면을 오래 열어둔 경우 새로고침 후 현재 안내를 확인해야 한다.

## 이전 제어 설정

서버 환경변수로만 제어한다. 관리자 역할, 쿠키, URL 매개변수로 우회할 수 없다. 현재 Sites에는 새 변수를 설정하지 않아 평소 이용을 유지한다.

| 설정 | 동작 |
|---|---|
| MIGRATION_MODE 미설정 또는 open | 평소 이용. CHECKOUT_ENABLED 미설정은 기존 동작 유지 |
| open + CHECKOUT_ENABLED=false | 신규 주문 생성만 503으로 차단. 기존 결제 승인 처리와 일반 이용 유지 |
| MIGRATION_MODE=drain | 모든 API와 사용자 페이지를 점검 상태로 응답. 기존 POST /api/payment-approve만 기존 검증 절차로 전달 |
| MIGRATION_MODE=frozen | 결제 승인 포함 모든 API 차단. 완전 동결 요청 모드 |
| 알 수 없는 MIGRATION_MODE 값 | frozen으로 차단. 오타 상태에서 운영이 열리지 않음 |
| GET /api/service-status | 저장소 접근 없이 mode·checkoutEnabled만 반환. 비밀값 미포함 |

점검 응답은 HTTP 503, no-store, Retry-After 300이다. 300은 재시도 간격이며 작업 완료 시간 약속이 아니다. GET에도 만료 처리·권리 차감·파일 삭제가 있으므로 변경 메서드만 막지 않고 API 전체를 막는다. drain/frozen에서는 요청으로 시작되는 일일 정리 작업도 시작하지 않는다.

**동결의 한계:** 설정이 반영되기 전에 이미 실행 중인 요청/백그라운드 작업은 취소되지 않는다. 설정 전파 확인, 진행 중 요청 종료, PG 원장 대사 후 마지막 백업을 확정해야 한다. 이니시스 실제 연동의 기존 미완료 사항을 이 기능이 해결하는 것은 아니다. 신규 PG 콜백 경로가 추가되면 drain 허용 목록과 시험을 함께 갱신한다. frozen은 지연 승인/입금 처리 계획 없이 켜지 않는다.

Cloudflare 신규 패키지 기본값은 drain + CHECKOUT_ENABLED=false이다. 운영 준비·검수 후 담당자가 open으로 전환하고 별도로 결제를 개방한다. 기존 랭크업의 중지 기능, 증분/삭제 장부, 역이전 importer, 실제 PG 대사/복원 리허설은 여전히 미완료다.

## 검증

단위 277개, 기존 Worker 흐름 565개, 신규 연락처·점검 제어 Worker 41개를 검증한다. 별도 이전자료 검증 12개와 Cloudflare 패키지 13개를 포함한 최종 결과는 STATUS/TEST의 배포 기록을 따른다. 신규 테스트는 실제 번호 변경·추가 제거·공개 철회·구매 후 보호와 점검 시 저장소/백그라운드 접근 0을 검사한다.

로컬 격리 DB에서 브라우저 연락처 폼·배너·한의사 순서를 확인했다. 시험 데이터는 운영 DB에 만들지 않았다. 정상 SQL 원본은 아직 없다. 받은 132바이트 파일은 다운로드 경로 오류문이며 실제 회원 백업이 아니다. 도메인/실결제 키/랭크업 자료 변경은 수행하지 않았다.
