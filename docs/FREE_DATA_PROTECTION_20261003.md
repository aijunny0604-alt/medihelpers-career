## 자동 복구 기록

Cloudflare D1의 [Time Travel](https://developers.cloudflare.com/d1/reference/time-travel/)은 자동으로 복구 기록을 유지하며 Free 요금제의 복구 범위는 7일이다. 별도 R2 구독이나 이번 작업의 유료 업그레이드는 없다. 현재 검수 DB에서 복구 bookmark 조회를 확인했다.

별도 임시 D1 `74c7b4e4-bde7-4acd-9e34-d4b47aabbd14`에 합성 행을 넣고 bookmark 확보 → 값 변경 → 해당 bookmark로 복구 → 변경 전 값 일치를 확인했다. 실제 회원 DB에는 Time Travel restore를 실행하지 않았다. 시험 DB는 삭제했다. 증거는 Git 밖 감사 폴더의 time-travel-*.json이다.

이는 동일 Cloudflare 계정 안의 시점 복구다. 계정 상실에 대비한 외부 자동 백업이나 7일을 넘는 자동 보관이 구축됐다는 뜻이 아니다. 현재 별도 SQL 내보내기와 파일 포함 복원 리허설 자료는 보호된 로컬 폴더에 보관한다. [전체 DB·파일 복원 검증](REMOTE_RESTORE_20261003.md).

## 만료 파일 정리

`server/d1Retention.js`와 Worker scheduled 핸들러를 추가했다. D1 업로드를 사용하는 경우에만 적용하며 R2 바인딩이 있으면 실행하지 않는다.

- 1회에 만료된 병원 서류 기록 최대5건, 7일이 지난 고아 파일 최대5개를 처리한다. 파일 본문은 읽지 않는다.
- 이력서와 제출된 상담 스냅샷에서 사용하는 사진, 아직 유효하거나 만료일이 잘못된 서류, 최신 서류 제출 정보, 병원 배너는 유지한다.
- 삭제 시점에 기한과 참조를 다시 검사한다. 연장된 서류, 다른 기록에서 공유하는 파일을 오래된 조회 결과만으로 지우지 않는다.
- 파일/청크/서류 기록/프로필 파기 표시/작업 로그를 하나의 DB batch로 처리한다. 로그 저장 실패를 포함한 중간 오류 시 롤백한다.
- 기존 R2 일일 정리도 읽기 전용 또는 점검 모드에서 실행되지 않도록 방어를 추가했다.

검수 설정에는 매시17분 Cron을 등록하되 **D1_RETENTION_ENABLED=false**를 유지한다. STAGING_READ_ONLY=true 또는 MIGRATION_MODE가 open이 아니어도 DB를 조회하거나 삭제하지 않는다. 정식 운영 준비 완료 전까지 자동 삭제를 활성화하지 않는다. 이 스케줄은 파일 정리이며 일반 회원/결제 원장 보관 정책의 자동 파기나 백업 내보내기를 실행하지 않는다.
