# 메인·병원채용 역할 분리

## 목적

메인 페이지와 병원채용 페이지가 같은 공고 목록처럼 보이지 않도록 역할을 분리하고, 유료 광고의 메인 노출 가치를 강화했습니다.

## 메인 페이지

- 브랜드 영상과 핵심 서비스 소개
- `지금 주목할 집중채용` 전용 프리미엄 쇼케이스
- 검수 정보, 메인 우선 노출, 핵심 조건 비교 안내
- 간결한 조건 검색 후 병원채용 페이지로 이동
- 광고가 아닌 최신 일반 공고 4개만 미리보기
- 전체 병원채용과 광고센터로 연결되는 명확한 버튼 제공

## 병원채용 페이지

- 전체 공고 검색과 비교
- 진료과, 지역, 근무조건, 키워드 필터
- 플래티넘·집중채용 광고 전체 순환 노출
- 일반 공고 전체 목록, 정렬, 더보기, 관심공고 기능

## 광고 노출 원칙

- 유료 집중채용 공고는 메인 전용 쇼케이스에서 일반 공고와 분리해 먼저 노출합니다.
- 메인의 최신 공고 영역은 일반 공고만 표시해 광고 영역의 의미가 흐려지지 않게 합니다.
- 병원채용 페이지에서는 유료 광고와 일반 공고를 등급과 영역에 따라 모두 제공합니다.

## 화면 톤 조정

- 메인의 프리미엄 쇼케이스는 짙은 파란 면 배경을 사용하지 않습니다.
- 기존 메인과 어울리는 흰색 바탕, 옅은 회색 테두리와 그림자로 가볍게 구분합니다.
- 파란색은 제목 보조 요소와 주요 버튼에만 제한적으로 사용합니다.
