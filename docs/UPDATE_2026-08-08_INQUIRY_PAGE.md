# 문의·후보 상세 독립 페이지 전환

## 변경 사항

- 마이페이지의 문의·후보 항목은 모달 대신 `/mypage/inquiries/{문의ID}` 독립 페이지로 열립니다.
- 문의 목록으로 돌아가기, 처리 이력, 접수 정보, 답변 작성 기능은 기존 권한과 서버 연동을 유지합니다.
- 과거 테스트 데이터에 물음표로 깨져 저장된 제목·보낸 사람·관련 항목·본문·접수 정보는 표시 단계에서 감지해 안전한 안내 문구로 대체합니다.
- 정상적인 한글 문의와 답변은 원문 그대로 표시합니다.

## 검증 항목

- 독립 상세 경로 라우팅
- 대시보드와 문의 목록의 상세 페이지 이동
- 기존 문의 모달 코드 제거
- 깨진 레거시 문자열 대체
- Node 자동 테스트, 프로덕션 빌드, Worker 문법 검사

## 보존 사항

- OpenAI Sites `project_id` 유지
- D1 `DB` 바인딩 유지
- R2 `BACKUPS` 바인딩 유지
- D1 레코드나 스키마를 삭제·재생성하지 않음
