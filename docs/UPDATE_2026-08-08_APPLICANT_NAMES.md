# 병원 지원자 실제 회원 이름 표시

## 변경 사항

- 신규 채용 지원은 사용자가 입력한 임시 문구 대신 로그인 계정의 회원가입 이름을 지원자 이름으로 저장합니다.
- 병원 마이페이지의 기존 지원 내역은 지원 이메일과 연결된 회원 계정·회원 프로필에서 현재 이름을 확인해 표시합니다.
- 연결된 회원 프로필 이름이 없을 때만 이력서 제출본의 이름, 기존 접수 이름 순서로 대체합니다.
- 이름을 확인할 수 없는 다른 계정을 임의로 연결하지 않습니다.

## 적용 화면

- 병원 마이페이지 `문의·후보`
- 채용 지원 상세 페이지의 `보낸 사람`
- 신규 지원 알림 및 병원 활동 이력

## 보존 사항

- 기존 D1 접수 레코드를 삭제하거나 재작성하지 않습니다.
- 기존 OpenAI Sites 프로젝트와 D1 `DB`, R2 `BACKUPS` 바인딩을 유지합니다.
