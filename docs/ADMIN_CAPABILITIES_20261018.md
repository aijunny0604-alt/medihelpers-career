# 관리자 회원 기능 접근 보완 — 2026-10-18

## 변경 사항

운영자가 관리자 로그인으로 열람권 구매 화면에 들어가도 병원회원 전용 안내만 나오던 문제를 수정했다. 화면과 주문 API 모두 병원 역할만 허용했고, 마이페이지도 관리자 콘솔 안내로 대체되어 본인 결제 결과를 확인할 수 없었다.

- 서버에서 인증한 관리자는 열람권·광고 신청, 본인 공고 수정, 이력서·구직글 작성, 병원 상담 기능에 접근한다. 저장된 계정 역할은 바꾸지 않는다.
- 상단의 **내 활동·결제**에서 관리자 본인의 공고·이력서·결제/환불·이용권을 확인한다. **관리자** 버튼은 전체 운영 콘솔로 연결한다.
- 관리자도 결제를 시작하면 본인 계정으로 실제 주문이 생성된다. PG 승인 이전에는 광고를 공개하거나 이용권을 지급하지 않는다.
- 인재 상세는 기존 관리자 권한으로 구매 없이 볼 수 있다. 관리자 조회는 구매한 이용권 횟수를 차감하지 않는다. 이용권을 구매하는 경우 결제 테스트·본인 거래로 기록된다.
- 관리자 본인의 회원정보에서 이름·연락처 등을 정정할 수 있다. 이메일, 계정 역할, 관리자 지정은 변경할 수 없다. 일반 회원의 기존 정보 정정 제한은 유지한다.
- 관리자 광고 신청은 해당 공고의 병원·기관명을 입력할 수 있다. 결제자 이름·연락처·이메일은 로그인한 관리자 프로필에서 서버가 가져온다.

## 권한과 거래 검증

관리자 판정은 인증된 자격 증명의 principal과 서버의 ADMIN_EMAILS 설정을 사용한다. 요청 본문의 isAdmin, 역할, 이메일 또는 헤더로는 관리자 권한을 얻지 못한다. 계정 정지·관리자 지정 해제·로그아웃 이후에도 권한이 유지되는지 부정 테스트로 확인한다.

본인 거래 API는 관리자에게도 account_id 소유권을 적용한다. 전체 고객 기록은 운영 콘솔에서 조회한다. 관리자 주문을 다른 병원이 재결제·환불하거나 수정하지 못하며, 관리자라는 이유만으로 PG 승인이나 환불 증빙을 생략하지 않는다.

`runtime-admin-capabilities-audit.mjs`는 생성된 Cloudflare Worker와 운영 변수 조합, 메모리 SQLite를 사용한다. 모든 PG 통신은 합성 응답으로 대체한다. 신규 81검사는 쿠키 없는 의료인·병원·관리자 비밀번호 로그인, 역할별 접근, 관리자 PC/모바일 주문, 재결제창, 모의 승인/수동 환불, 공고 게시·수정, 프로필 변조 차단, 구직글 작성·삭제, 정지/권한회수/로그아웃을 검증한다.

전체 **24묶음 2,766검사**와 일반·Cloudflare 빌드, 두 생성 Worker 문법 검사를 통과했다. 기존 병원·의료인 권한 분리, 결제 494검사, 환불 160검사도 포함한다. 이는 실제 카드 승인이나 실제 카드 취소의 성공을 의미하지 않는다.

별도 Cloudflare D1 `medihelpers-admin-proof-20261018`에서도 **63검사**를 통과했다. 실제 비밀번호 로그인으로 의료인·병원·관리자를 구분하고, 관리자 PC/모바일 서명 주문 준비와 동일 주문 재개, 서명 없는 승인 거절을 확인했다. 운영 D1에는 합성 계정·주문을 만들지 않았다. 운영 관리자 조회에서 이름·이메일은 있으나 전화번호가 비어 있음을 확인해 임의 대입 없이 본인 입력 동선을 제공한다.

## 운영자 확인 경로

1. 새로고침 후 관리자 로그인 상태에서 `/talent-unlock?product=talent-unlock-single`에 접속한다.
2. 결제 연락처가 비어 있으면 `/mypage?tab=profile`에서 관리자 본인의 이름·연락처를 저장한다. 연락처는 임의로 채우지 않는다.
3. 소액 시험을 원할 때만 3,900원 결제를 직접 진행한다.
4. `/mypage?tab=payments`에서 결제와 이용권 수량을 확인하고 환불을 요청할 수 있다.
5. 실제 취소는 기존 이니시스 관리자에서 처리한 뒤 홈페이지 운영 콘솔에 취소 근거를 기록한다. 자동 INIAPI 환불은 활성화하지 않았다.

기존 랭크업 원본·복구 경로, 이전회원 282명의 보류, production D1·PG 키·DNS를 유지한다. 이 작업에서 실결제·실환불, 운영 시험 회원·시험 주문 생성은 수행하지 않는다.
