# 구직글 공개 기간과 연락처 안내

## 2026-09-15 — 연락처 안내와 구직글 공개 관리

열람권 상세의 면허·자격 행을 제거했다. 연락처 공개/비공개는 작성자가 구직글 등록·수정에서 선택하는 기존 정책을 유지한다. 외부 게시판의 공개·비공개 배지를 확대하고, 비공개 대상 결제에는 전화번호·이메일 미제공 안내와 확인 체크를 추가했다. 결제 사전 조회는 열람권을 소비하지 않으며, 결제 중 공개→비공개 변경 시 주문 생성을 중단하고 안내를 갱신한다.

구직글은 마지막 등록·내용 수정·재공개 후 한국 달력 기준 5개월이 지나면 자동 비공개한다(말일 보정). 단순 로그인·조회·별도 이력서 수정은 기간을 연장하지 않는다. 마이페이지와 구직글 수정 화면에서 상태·예정일 확인, 수동 비공개·재공개·삭제가 가능하다. 비공개 글의 내용 수정만으로는 다시 공개되지 않는다. 재공개는 기존 연락처 설정을 유지하고 5개월을 새로 계산한다. 자동 비공개는 삭제가 아니며 작성자는 계속 조회·수정할 수 있다.

DB 마이그레이션 `0014_job_post_visibility.sql`로 `public_until`, `hidden_reason`, 상태/기한 인덱스를 추가한다. 기존 글은 updated_at 기준으로 기한을 보정한다. 공개 목록·상세·결제·회원 조회 전 서버에서 기한을 검사하고 기존 요청 기반 일일 정리에서도 실행한다. 무접속 시각에 별도 스케줄러가 DB를 갱신하는 구조는 아니지만 다음 외부 조회 전에 비공개 처리한다. member_activity에 자동 전환 이력을 중복 없이 남긴다. DB/R2 바인딩과 테스트 로그인·역할은 유지한다.

검증: 단위 245, 열람권/공개관리 76, 관리자·저장 63, 통합 106, 경쟁/예외 58, 준비도 67 — 총 615개 통과 및 빌드 성공. 격리 SQLite에 전체 마이그레이션 적용 후 테스트했다. 브라우저에서 비공개 연락처 확인 체크 누락 차단→가상 결제→연락처 미제공, 의사의 연락처 변경 저장, 자동 비공개 글 재공개/수동 비공개, 외부 배지 반영을 확인했다. 390px에서 관리 버튼 48px·가로 넘침 없음 확인. 운영 DB에 시험 게시글·주문을 추가하지 않았다. 배포 결과는 후속 기록한다.

## 검증 경계

운영 사이트는 가상 결제 단계이며 실제 PG 청구를 검증한 결과는 아니다. 이미 열람·별도 저장된 자료를 원격 회수하지는 않는다. 비공개 후 새 서버 조회와 오래된 이력서 경로의 구매·상세·사진 접근을 차단한다. 결제 승인 전 대상이 사라지면 기존 처리에 따라 사용 가능한 크레딧을 보존한다. 연락처 원문은 현재 글의 공개 동의가 있을 때만 서버에서 제공한다.
