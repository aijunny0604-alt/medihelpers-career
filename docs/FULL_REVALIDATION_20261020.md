## HTTPS와 직접 화면 확인

HTTP 검사는 홈·채용·의료인·헤드헌팅·광고·가입·로그인·복구·마이페이지·이력서·약관 등 20개 URL의 응답과 5개 보호 조건을 확인했다. HTML 200은 페이지 껍데기의 정상 응답이므로 역할별 기능 검증과 구분한다. 이번 단일 조회에서 최대 응답 시간은 544ms였으며 운영 데이터의 로딩 속도나 부하 성능을 보장하는 수치가 아니다.
