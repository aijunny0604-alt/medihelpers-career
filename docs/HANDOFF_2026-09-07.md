## 상품·결제 정책

### 병원 채용광고

- 베이직 광고는 59,000원, 메인 광고는 149,000원이며 모두 결제일을 포함해 30개 달력 날짜 동안 노출합니다.
- **공고를 올릴 때마다 새 주문과 새 결제가 필요합니다.** 주문 1건은 공고 원장 1건에만 연결되며, 한 번 결제했다고 다른 공고를 계속 등록할 수 없습니다.
- 결제 승인 전에는 공고가 `draft`이고, 가상 또는 실제 PG 승인이 성공한 주문의 연결 공고 1건만 `published`로 전환됩니다.
- 같은 주문의 승인 요청이 반복되어도 멱등성 검사로 중복 공고·중복 거래를 만들지 않습니다.
- 결제된 기존 공고의 내용 수정은 재결제 없이 가능하지만 노출 종료일이 늘어나지는 않습니다. 새 공고 등록, 재등록 또는 노출기간 갱신은 새 주문·결제가 필요합니다.
- 무료 공고 생성 API는 차단되어 있으며 병원 회원만 광고 상품을 주문할 수 있습니다.
- 메인 광고만 배너를 사용합니다. 베이직 광고는 배너 입력과 배너형 카드를 사용하지 않습니다.

### 인재 열람권

- 상품은 1명 3,900원, 10명 29,000원, 30명 69,000원입니다.
- 30일 이용권이나 기간 내 무제한 상품이 아니라 **잔여 인원 수량제**입니다.
- 병원이 새 인재를 처음 열 때만 1건을 차감하며 같은 인재 재열람은 추가 차감하지 않습니다.
- 기간 만료는 없고 잔여 수량이 0이면 새로운 인재의 상세 권한을 발급하지 않습니다.
- 병원명·담당자 연락처·이메일은 병원 회원가입 DB 원본을 결제 화면에 읽기 전용으로 표시하고 주문 서버에서도 같은 원본으로 확정합니다.
- 구직자가 연락처 비공개를 선택한 글은 열람권이 있어도 전화번호와 이메일을 공개하지 않습니다.

- 헤드헌팅 상세의 페이지 폭·글꼴·조건 카드와 뒤로가기 버튼을 확대했습니다.
- 구직글 작성·수정 화면의 이력서 관리는 페이지 이동 없이 모달에서 선택합니다.
- 병원 공고 등록은 가입 프로필의 병원명·기관 유형·담당자·연락처·이메일·주소·홈페이지·대표자·사업자번호를 자동 입력합니다.
