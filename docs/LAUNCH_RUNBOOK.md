## 확정한 방향과 확인한 증거

- 기존 랭크업 호스팅·DB·첨부·관리자 접근은 유지한다. 해지·삭제·기존 PG 키 교체는 이번 작업에 포함하지 않는다.
- 대표 도메인은 기존 medihelpers.co.kr을 이어 쓴다. 배포 소스의 대표 주소는 https://www.medihelpers.co.kr이며 현재 www/apex 모두 기존 서버다. HTTPS와 apex→www 연결은 최종 전환에서 검증한다.
- 사용자 제공 이니시스 계약 화면에서 MID `UPmedihelp`, 홈페이지 `medihelpers.co.kr`, 사용 상태, 계약일 2017-10-19를 확인했다. 이후 관리자에서 기존 사용 상태와 카드사 등록을 확인했다. 새 환경의 실제 승인·취소 호환성까지 입증한 것은 아니다.
- 부가정보 화면의 면세 표시·자동 매입·현금영수증 사용·월1회 정산은 현재 PG 화면 설정이다. 새 상품의 세무 처리나 수수료·새 모듈 사용 권한까지 확정한 증거는 아니다. 상품별 금액/과세 설정을 담당자에게 확인한다.
- Cloudflare 검수 환경과 메일 연결·수신 확인,281명 보호 반입은 진행됐다. 회원은 활성화 보류이며 실제 역할 로그인·실카드 승인/취소는 미완료다. 테스트 전환/예시 데이터는 운영 빌드에서 제외하고 로컬에서는 유지한다.

## 중단 조건과 기록

개인정보 무단 노출, 소유권 뒤바뀜, 중복 청구, 금액 불일치, 권리 중복 지급이 한 건이라도 확인되면 신규 쓰기/주문을 즉시 중지하고 [복구 실행서](ROLLBACK_RUNBOOK.md)를 따른다. 결제 승인 상태 미상은 재결제를 유도하지 않고 PG 조회·원장 대사로 해결한다.

운영 수치 기준 초안: 핵심 로그인/게시/주문 경로 연속 3회 실패 또는 5분간 서버 오류율 1% 초과 시 신규 개방을 중단한다. 최소 표본·관측 도구·복구 판단 제한 시간은 리허설 후 운영 책임자가 확정한다. 관측 불가도 개방 승인 근거가 될 수 없다.

실행 기록 양식: 실행번호 / 시작·완료시각(KST와 UTC) / 담당 / 소스 SHA / 데이터 기준시각 / 증거 위치 / 결과 / 예외 / 승인자. 실제 운영 자료는 접근 제한된 운영 저장소에 보관한다.
