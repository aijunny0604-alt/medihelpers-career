# 열람권·결제 검수 — 2026-10-18

## 배포 후보와 범위

정식 사이트의 결제 설정 및 운영자 접근 23검사 통과. PC 결제 SDK·닫기 SDK가 이니시스 공식 주소에서 HTTP200으로 제공된다. PAYMENT_LIVE/INICIS_ENV/live, 모바일 사용, 서버 Secret 등록, 체크아웃 활성화, 수동 환불 방식과 테스트 역할 전환 차단을 확인했다. 키 값 자체의 유효성과 카드사 승인은 실제 거래 없이는 확정하지 않는다.

실제 카드 승인·취소는 수행하지 않았다. 새 사이트의 실 주문·승인·환불 기록은 검수 시점 모두 0건이다. 격리 환경의 승인 시뮬레이션을 실제 PG 승인으로 보고하지 않는다. 기존 랭크업·운영 키·면세 설정·보류 회원은 유지한다.

## 발견 및 수정

1. 실제 결제 화면에 남아 있던 ‘가상 결제·청구되지 않음’ 문구를 제거했다. 금액이 포함된 결제 버튼, 승인 전 미지급 안내, 결제 중단 안내를 표시한다. 로컬 가상 결제 완료 문구는 서버가 테스트 모드로 응답할 때에만 남긴다.
2. 같은 이력서에 연결된 여러 구직글/이전 이력서 주소로 접근하면 횟수가 중복 차감될 수 있었다. 구매 조회·결제 재개·지급·차감·대량조회 제한에 동일 이력서 기준을 적용했다. 동시 요청도 DB의 원자적 처리 안에서 중복을 방지한다.
3. 주문별 지급·사용·잔여·환불 검토 보류 수량을 마이페이지 결제 내역에 표시한다. 결제 승인 전과 지급 확인 중을 구분하며, 전액 환불의 권한 회수용 카운터를 실제 사용 수로 표시하지 않는다.
4. 잔여 수량이 0인 팩도 누적 지급/사용 합계에 포함한다. 환불요청 직후에는 서버의 최신 이용 가능 수량을 다시 읽는다. 계정이 바뀌면 열람권 상태도 다시 조회한다.
5. 최종 UI 검수에서 추가한 목록 배지의 잘못된 변수 참조를 수정하고, 실제 목록 렌더링을 확인했다.
