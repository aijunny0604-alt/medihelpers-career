# 병원 확인용 사업자등록증 — 2026-09-13

## 사용자 결정

사업자등록증의 유일한 용도는 기관 정보 확인 및 허위·도용 가입 방지다. 사용자는 복잡한 절차 없이 적용하도록 요청했다. 가입·로그인·테스트 역할 전환은 즉시 사용 가능하게 유지한다. 보호책임자 이형석 / hr@medihelpers.co.kr / 051-342-5463은 변경하지 않는다.

## 구현

- 업로드 바로 아래 기본 미선택 필수 체크박스 하나와 목적·항목·보유기간·거부 시 영향을 담은 펼침 안내를 둔다. 기존 전체 동의는 아래 약관·안내·연령만 대상으로 하며 서류 동의를 대신하지 않는다.
- `hospitalDocument` 별도 범위, 안내 사본·버전·대상 서류 식별자·서버 기록 시각을 `processing_consent_events`에 가입 데이터와 같은 배치로 저장한다. 현재 양식 버전은 `privacy-forms-v1.2-2026-09-13`, 공개 처리방침은 v1.2(9월 13일)다. 동의가 없거나 문자열 true, 구버전이면 파일·계정을 만들기 전에 거절한다.
- 서류 원본은 비공개 R2에만 보관한다. 30일은 이번 서비스 운영상 선택한 상한이며 법정 의무 보관기간이라는 의미가 아니다. 확인 완료 시 먼저 삭제하고, 미확인 서류는 제출 후 30일이 되면 열람을 차단하고 보존 정리에서 삭제한다.
- 기존 3년 설정도 제출 시각+30일로 단축한다. 회원이 직접 입력한 병원명·대표자·사업자번호·주소는 먼저 `member_registration_profiles`로 분리해 공고 자동입력을 유지한다. 이미 입력된 기본값은 덮어쓰지 않는다.
- 관리자 회원 기록에 ‘기관 확인 완료 · 원본 삭제’ 버튼 하나를 추가한다. 기관 정보와 담당자 소속을 실제 확인한 운영자가 사용한다. 가입 승인·반려 또는 로그인 게이트가 아니다. 다른 관리자 데이터 변경 API는 계속 405다.
- 자동 업로드 이력과 실제 확인을 구분한다. 과거 `approved/system-auto`, `verification_status=verified`는 호환용으로 남고 확인 증빙으로 취급하지 않는다. 실제 상태는 가입 프로필 `hospitalDocument.status=submitted|checked|expired`와 확인/삭제 시각이다. 파일·원본 파일명·해시·중복 서류 메타데이터는 파기한다.
- 원본 삭제 실패는 성공으로 표시하지 않는다. 먼저 열람을 차단하고 DB에 재시도 정보를 남긴다. R2 삭제 후 DB 실패도 재시도 가능하며, 원본 목록에 파일이 없어도 DB 만료 목록으로 복구한다. 탈퇴 시 아직 유효한 확인 서류도 정리한다.

## 운영 범위

자동 파기는 현재 한국 날짜 하루 첫 사이트 요청에 따른 보존 실행에 의존한다. 트래픽이 없으면 파일의 물리 삭제는 다음 요청까지 지연될 수 있고 정각 실행 보장은 없다. 만료 문서는 GET에서 제공하지 않는다. 정식 운영에서 무트래픽 파기를 보장하려면 예정된 Cloudflare 이전 시 Cron 실행을 붙인다.

DB 백업에는 원본 파일 바이트가 없으며, 이전 제출 메타데이터는 백업 순환 35일 규칙에 따라 제거된다. 삭제 후 과거 백업을 복구할 때 같은 30일 보존 정리를 먼저 적용한다. 보관기간 변경을 동의의 소급 취득으로 간주하지 않으며 과거 미동의 서류에 새 동의 기록을 만들지 않는다.

사업자등록증 업로드 또는 운영자 버튼만으로 서류 진위·소속이 자동 인증되는 기능은 아니다. 운영자가 실제 확인해야 한다. 실PG·외부 전달·수탁계약·국외 이전·법률 검토 잔여 항목은 기존 통합 검수와 동일하다.
