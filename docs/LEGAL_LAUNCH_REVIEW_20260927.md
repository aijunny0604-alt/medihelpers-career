# 운영 전환 법무·세무 검수표

기준일: 2026-09-27. 사용자의 법적 요건 점검 요청에 따른 출시 전 검수 문서이며, 법률 적합성 확인서가 아니다. 법령의 시행일과 실제 계약·운영 형태를 대조해야 한다. 미시행 개정법을 현행 의무로 적용하지 않는다.

## 실제 확인한 사실

- 이니시스 관리자에서 UPmedihelp 사용 상태와 카드·계좌이체·가상계좌 계약 항목을 확인했다.
- 웹결제 Sign Key 조회 화면에는 기존 값이 있다. 비밀값은 문서·대화·소스에 기록하지 않았으며 생성/갱신하지 않았다.
- INIAPI 조회 팝업에서 KEY·IV 입력란은 비어 있고 `생성` 버튼이 표시된다. 발급 또는 서비스 이용 가능 여부를 확정한 것은 아니다. 생성하지 않았다.
- 이니시스 부가정보의 카드 표시 설정은 면세 100%이고 새 앱에는 10% 부가세 분리 계산이 있다. PG 화면만으로 상품의 세법상 면세 여부를 판단하지 않는다.
- Cloudflare 테스트 DB에는 실제 회원을 이전하지 않았다. 실결제·회원가입·쓰기 차단을 유지한다.

## 확인 절차

1. 개발팀: 화면·서버 권한·동의 증빙·취소 및 권리 회수의 일치 여부를 검증한다.
2. 운영자: 기존 신고/등록 증빙, PG 계약, 개인정보 처리 계약과 상품 정책을 확인한다.
3. 세무 담당자: 상품별 과세·면세와 영수증 처리를 확정한다.
4. 필요 쟁점은 관할기관/법률 전문가에게 문서화해 확인한다. 답변 수신 전 해당 항목을 완료 처리하지 않는다.
5. 실제 회원 이전, 실결제 활성화, DNS 전환 전 증거와 담당자 확인일을 남긴다. DNS 복구만으로 신규 거래·회원 변경분이 되돌아가지 않음을 복구 계획에 반영한다.

## 공식 참고 자료

- [직업안정법 제23조](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0023&lsiSeq=259231&urlMode=lsScJoRltInfoR): 직업정보제공 신고와 소개사업 예외 구분. 출시일 시행본 재확인.
- [디지털콘텐츠 표준약관](https://www.law.go.kr/admRulLsInfoP.do?admRulSeq=2100000216089): 철회·환급 검토 참고이며 당사 모든 상품에 자동 적용되는 약관은 아니다.
- [INIAPI 취소 매뉴얼](https://manual.inicis.com/pay/cancel.html): 결제 취소 기술 요건. 소비자법상 환불 의무 판단을 대신하지 않는다.

공개 약관의 즉시 개정·계약 제출·PG 키 생성·세금 설정 변경은 이번 읽기 전용 확인에서 실행하지 않았다.
