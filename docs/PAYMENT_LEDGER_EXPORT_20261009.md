# 결제 대조용 원장 다운로드 — 2026-10-09

기준 소스 ea380d8에서 관리자 결제·환불 원장에 날짜별 CSV 다운로드를 추가했다. 기존 화면의 최근 기록 제한에 의존하지 않고 저장된 성공 이니시스 승인·취소 거래를 조회한다.

## 사용과 범위

1. 관리자 → 결제·환불 원장에서 한국 날짜 기준 시작일과 종료일을 선택한다.
2. 대조용 CSV를 내려받고 이니시스 관리자 거래 내역과 원 TID·금액·승인/취소 상태를 대조한다.
3. PG에서 취소했으나 홈페이지에 아직 반영하지 않은 거래는 수동 환불 절차에 따라 확인·기록한다. CSV에 없다는 이유로 다시 카드 취소를 요청하지 않는다.

날짜 필터는 **홈페이지 기록시각** 기준이다. 지연 반영을 구분하도록 실제 PG 취소시각을 별도 열에 표시한다. 이니시스에서만 발생한 미반영 취소를 자동으로 가져오거나 발견하는 기능은 아니다. 이니시스 정산 명세서를 대신하지 않는다.

최대 31일, 10,000행까지 허용한다. 초과하면 기간을 줄이도록 오류를 반환하며 일부만 조용히 내보내지 않는다. 주문번호·원 TID·거래구분·금액·홈페이지 기록시각·PG 취소시각·현재 주문상태·확인방식의 8열을 제공한다. 고객 이름·전화·이메일 및 확인 근거 원문은 제외한다. 파일에는 여전히 거래 식별자가 있으므로 운영 자료로 관리한다.
