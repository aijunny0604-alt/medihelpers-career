# 메인 검색·조회 개선 배포 검수

기준일: 2026-10-19. 시작 소스 `372560e28ba13b0511c156e45e6266107494c2a1`.

## 이번 변경

- 메인 조건검색에 검색어 입력을 복구했다. 입력 즉시 건수와 최대 4개 공고를 표시하며, Enter와 전체 결과 링크는 같은 검색어·진료과·지역·초빙유형을 채용 페이지로 넘긴다.
- 공개된 표시 필드에서 대소문자·전각·띄어쓰기 차이를 정규화하고 여러 키워드는 순서와 무관하게 모두 일치해야 한다. `인천내과`처럼 붙여 쓴 검색어는 실제 필드에 존재하는 단어로만 분리한다. 임의 오타 교정이나 숨겨진 회원 정보 검색은 하지 않는다.
- 홈 조회 실패 때 홈페이지 전체가 오류 화면으로 바뀌던 동작을 검색 영역의 오류·재시도로 바꿨다. 서버 오류를 성공 또는 공고 0건으로 숨기지 않으며, 상세/권한 조회는 기존 검증을 유지한다.
- 앞선 미배포 수정(선택동의 없는 가입, 신규 아이디, 병원 주소 직접 입력, 직군 구분, 영상 자동 재생, 공고 링크·구조화, 공개 조회의 반복 DB 쓰기 감소)을 같은 배포 후보에 포함한다.

## 배포 전 확인

- GitHub 기준 브랜치와 Sites 미러 시작 SHA 일치, 별도 Claude 작업본 미커밋 없음.
- 전체 25묶음 **3,102검사** 통과, Sites/Cloudflare 두 빌드 및 Worker 문법 검사 통과.
- 격리 브라우저에서 실제 공개 공고의 `송도 JK`, `JK 송도`, `JK워드미`가 같은 1건을 찾고 Enter 후에도 동일 결과인 것을 확인했다. 현재 공고 원문 병원명이 `JK 워드미`인 점과 사용자가 쓴 `위드미`를 임의로 동일 철자로 간주하지 않는다.
- 운영 공개 API 사전 1회 측정: HTTP200, 약 2.74초. 반복 지연의 단일 원인 확정 또는 개선 후 성능을 의미하지 않는다.
- Cloudflare 인증을 완료했다. 운영 D1 4,986,830바이트 백업을 저장소 밖에 보관하고 격리 SQLite 복원: 49테이블, integrity ok, 외래키 오류 0.

## 상태와 범위

이 문서는 배포 후보의 검수 기록이다. 실제 배포 버전과 정식 URL 검증 결과는 후속 기록으로 확정한다. 기존 회원 원본·비밀번호 이전은 사용자 요청으로 보류한다. 의사 면허 확인을 추가하지 않았다. 실카드 결제·실제 메일 발송·실기기 Safari 검증은 이번 변경 범위에 포함하지 않는다.
