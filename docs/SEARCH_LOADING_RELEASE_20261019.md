## 이번 변경

- 메인 조건검색에 검색어 입력을 복구했다. 입력 즉시 건수와 최대 4개 공고를 표시하며, Enter와 전체 결과 링크는 같은 검색어·진료과·지역·초빙유형을 채용 페이지로 넘긴다.
- 공개된 표시 필드에서 대소문자·전각·띄어쓰기 차이를 정규화하고 여러 키워드는 순서와 무관하게 모두 일치해야 한다. `인천내과`처럼 붙여 쓴 검색어는 실제 필드에 존재하는 단어로만 분리한다. 임의 오타 교정이나 숨겨진 회원 정보 검색은 하지 않는다.
- 홈 조회 실패 때 홈페이지 전체가 오류 화면으로 바뀌던 동작을 검색 영역의 오류·재시도로 바꿨다. 서버 오류를 성공 또는 공고 0건으로 숨기지 않으며, 상세/권한 조회는 기존 검증을 유지한다.
- 앞선 미배포 수정(선택동의 없는 가입, 신규 아이디, 병원 주소 직접 입력, 직군 구분, 영상 자동 재생, 공고 링크·구조화, 공개 조회의 반복 DB 쓰기 감소)을 같은 배포 후보에 포함한다.
