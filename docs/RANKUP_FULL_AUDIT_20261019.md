## 증거·운영 제한

비공개 `work/private-rankup-audit-20261019/`의 DNS/TLS/HTTP/관리자 집계/결제 설정 비교/모바일 결과를 보관한다. 증거는 비밀값·회원 원문을 포함하지 않는 집계와 상태 중심이다. 전달용 화면은 공개 결제 폼과 모바일 화면이며 관리자 키 화면은 제공하지 않는다.

신규 앱은 재배포하지 않았고 www/apex Route를 다시 만들지 않았다. 소스와 문서만 GitHub 기준 브랜치 및 Sites 보관 미러에 동기화한다. 신규 앱 전체 3,102검사는 이전 개발 검수 수이며 이번 랭크업 점검에 재사용하지 않는다. 이번 문서 18개 상대 링크 420개·`git diff --check`·`npm run build`가 통과했다. 기준 브랜치 fetch 후 기존 HEAD와 원격의 앞뒤 커밋 차이 0/0을 확인하고 문서를 갱신했다.
