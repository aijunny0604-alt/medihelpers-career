2026-09-27 사용자 결정: 실제 medihelpers.co.kr 배포 요청, 기존 게시글/병원 광고 이전, 배포본의 테스트 계정 전환/예시 제거, 로컬 테스트 유지. 기존 Rankup 삭제·해지·키 재발급 금지. Rankup 고객지원 문의는 보류하며 발송하지 않았다.

## 구현

- Vite 개발 서버는 예시 공고/인재/테스트 계정/QA를 유지한다. 기본 release build에서는 예시 배열과 테스트 전환 목록을 비우고 QA 저장값을 무시한다. 실제 회원/관리자 인증 경로는 유지한다. 개발용 배포가 필요한 경우에만 VITE_DEMO_MODE=true를 명시한다.
- 회원/관리자 결제 확인서가 저장된 부가세 0원을 10%로 다시 계산하던 오류를 수정했다. 누락·불일치 금액은 확인 필요로 표시한다. 자체 확인서를 세금계산서/카드 매출전표로 표시하지 않는다.
- 실제 PG 주문은 서버의 상품별 세금 정책과 MID 계약 유형이 일치해야 생성한다. 누락/불일치/키 불완전 시 주문 저장 전 차단한다. 요청자가 보낸 taxSnapshot은 무시하고 서버 계산으로 대체한다.
- 업체정함 계약에만 tax/taxfree를 전송한다. 과세/면세 고정 계약에는 전송하지 않는다. 공식 규격: https://manual.inicis.com/pay/stdpay_pc.html
- 현재 어댑터는 카드 전용이므로 다른 결제수단을 카드로 오인해 접수하지 않도록 거부한다.
- 사용자 답변 “걍 기존 쓰던대로 해”에 따라 기존 MID의 면세 설정을 이어가는 정책으로 구성했다. staging의 판매중 5개 상품을 exempt로 지정했다. PG 관리자 설정/기존 거래를 변경하지 않았다. 세무 적법성에 대한 전문가 확인을 받았다고 기록하지 않는다.

## 기존 공고 확보와 검수 DB 복사

- 관리자 공고 9페이지, 127개 고유 원본 URL/번호를 대조했다.
- 상세 127건의 화면 본문·표 항목·이미지 URL을 확보했다. 관리자 목록의 서비스 종류/무기한 또는 시작~종료 기간을 번호로 연결했다.
- 원본 이미지 91개, 총 5,057,926바이트 다운로드 성공. SHA256 기록. 기존 도메인 변경 후 원본 이미지가 끊기지 않도록 향후 새 저장소의 주소로 치환해야 한다.
- 예: JK워드미 의원 프리미엄로고 2026-07-17~2027-01-17, 청아병원 프리미엄배너 무기한, 삼천포제일병원 프리미엄우대 무기한. 서비스 설정 확인이며 실제 결제 영수증 대사는 별개다.
- Cloudflare **medihelpers-staging**에 127건을 `rankup-job-<원본번호>`로 복사했다. 전부 `draft` + `visibility=admin`. 원본 날짜/서비스 문구/이미지 해시를 보존했다. 로컬 SQLite에서 동일 SQL 두 번 적용 후 127건 유지 검증. 원격 조회: 총 127 / 보호 초안 127 / 공개 0.
- 기존 회원과의 소유권 연결, 만료/현재 노출 여부, 이미지 배치, 옛 URL 리다이렉트, 광고 상품 등급 대응은 후속 검수 대상이다. 가짜 신규 결제/권리를 만들지 않았고 기존 PG 거래를 재청구하지 않았다.
- 로컬 자료: `C:/Users/ROSSA/medihelpers-audit-20260927/rankup-{jobs-inventory,job-details,ad-rights,image-manifest,drafts,migration-summary}.json`, `rankup-images/`, `rankup-drafts.sql`. 회원/관리자 정보가 포함될 수 있어 Git·공개 asset에 넣지 않는다.
- 이것은 전체 DB/회원/결제 백업이 아니며, 정상 전체 백업의 기존 차단 조건을 해제하지 않는다.
