## 구현

- Vite 개발 서버는 예시 공고/인재/테스트 계정/QA를 유지한다. 기본 release build에서는 예시 배열과 테스트 전환 목록을 비우고 QA 저장값을 무시한다. 실제 회원/관리자 인증 경로는 유지한다. 개발용 배포가 필요한 경우에만 VITE_DEMO_MODE=true를 명시한다.
- 회원/관리자 결제 확인서가 저장된 부가세 0원을 10%로 다시 계산하던 오류를 수정했다. 누락·불일치 금액은 확인 필요로 표시한다. 자체 확인서를 세금계산서/카드 매출전표로 표시하지 않는다.
- 실제 PG 주문은 서버의 상품별 세금 정책과 MID 계약 유형이 일치해야 생성한다. 누락/불일치/키 불완전 시 주문 저장 전 차단한다. 요청자가 보낸 taxSnapshot은 무시하고 서버 계산으로 대체한다.
- 업체정함 계약에만 tax/taxfree를 전송한다. 과세/면세 고정 계약에는 전송하지 않는다. 공식 규격: https://manual.inicis.com/pay/stdpay_pc.html
- 현재 어댑터는 카드 전용이므로 다른 결제수단을 카드로 오인해 접수하지 않도록 거부한다.
- 사용자 답변 “걍 기존 쓰던대로 해”에 따라 기존 MID의 면세 설정을 이어가는 정책으로 구성했다. staging의 판매중 5개 상품을 exempt로 지정했다. PG 관리자 설정/기존 거래를 변경하지 않았다. 세무 적법성에 대한 전문가 확인을 받았다고 기록하지 않는다.
