# 모바일 애니메이션 재검수

2026-10-20. 새 사이트의 모션을 켠 상태로 검사했다. 기존 랭크업·정식 도메인·DNS·운영 Worker·DB·PG는 변경하지 않는다. 배포 대상은 전용 QA Worker `medihelpers-payment-qa-20261020`뿐이며 Sites 공개 버전378은 유지한다.

## 수정한 문제

1. 의료인 공고 상세의 모바일 고정 버튼이 화면 밖으로 밀렸다. 페이지 전체의 transform 애니메이션과 `fill-mode:both`가 fixed 요소의 기준점을 바꾼 원인이다. 높이800px에서 버튼 하단이3392px에 있던 현상을 재현했다. 780px 이하 페이지 전환을 opacity 페이드로 바꾸고 transform을 제거하여 하단800px로 복원했다. 애니메이션은 유지한다.
2. 스크롤 진행률을 문서 루트의 상속 CSS 변수에 매 프레임 쓰던 처리를 표시줄 자체의 transform으로 한정했다. DOM 참조를 재사용하고 값이 같으면 중복 쓰기를 건너뛴다. 화면 크기 변경, 탄성 스크롤 범위, 페이지 이탈 시 예약 프레임 정리도 검사했다. 실제 기기 FPS 향상 수치를 측정한 것은 아니다.

## 실제 브라우저 범위

Windows 내장 Chromium 브라우저의 화면 크기 조절 검사다. `prefers-reduced-motion:reduce=true`에서도 `force-motion`이 활성화된 상태로 진행했다.

- 360×800, 390×844, 412×915, 768×1024에서 홈·채용·의료인·헤드헌팅·광고 안내·공고 등록·가입·로그인·계정 복구·결제 내역·이력서·환불 등 13경로, 52개 조합에 페이지 전체 가로 넘침 없음.
- 위 검사 중 가입 화면은 로그인한 계정의 회원 유형 안내였고 로그인 경로는 홈으로 이동했다. 이를 실제 가입 폼 검사로 계산하지 않았다.
- 로그아웃 후 의료인 가입·병원 가입·로그인 폼을 네 가지 폭에서 추가 검사한 12개 조합도 가로 넘침 없음.
- 의료인 상세 하단 버튼: 폭360·390·412·760에서 화면 하단에 고정됨. 768에서는 기존760px 기준에 따라 모바일 버튼이 숨겨짐. 다섯 폭 모두 가로 넘침 없음.
- 360px에서 모바일 메뉴 열기·닫기와 스크롤 잠금 해제, 도우미 패널, 지역 선택창의 화면 안 배치와 서울 선택 후 결과2건 표시 확인.
- 병원 가입의 추가 정보와 약관 내용을 펼친 상태에서도 가로 넘침 없음. 약관 동의·신규 회원 생성·실제 결제는 이번 화면 검사에서 수행하지 않음.
- 로컬 브라우저 오류 로그 조회 결과0건.

공고 상세는 로컬 합성 데이터로 검수했다. 실제 Android/iPhone, iOS Safari, 소프트웨어 키보드, 저사양 휴대폰의 FPS·발열·배터리는 측정하지 않았다. 일반 모션 설정은 앞선 자동검사에서 확인했으며 이번 OS 설정 변경 실행은 하지 않았다. 기기 전체에서 버벅임이 없다는 보증은 아니다.
