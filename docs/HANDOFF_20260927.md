## 완료한 작업

- 의료인 130명·병원 151명, 총 281명을 검수 D1에 보호 반입했다. 기존 아이디별 계정이며 이메일을 공유하는 13그룹·36계정도 합치지 않았다.
- 원본 상태와 로그인 후보 검증 전이므로 활성 회원은 0명이다. `suspended`와 `MIGRATION_HOLD`는 이전 검수 보류이며 원래 정지회원이었다는 뜻이 아니다.
- 공고 초안 127건 중 정확한 기존 아이디로 병원 소유권 126건을 연결했다. 소유자 미확인 1건은 보류했다. 기존 광고 기간 메타데이터를 보존했으며 공개·권리 지급은 하지 않았다.
- 결제 주문이 없는 기존 공고가 마이페이지에서 빠지는 문제를 수정했다. 계정 ID와 로그인 주체가 모두 일치한 본인 공고만 ‘이전 확인 중’으로 보여주며 내부 매핑·원본 JSON·다른 병원의 공고는 반환하지 않는다.
- 비공개 원본 보관함 1,205건을 유지했다. 기존 공고 이미지 91개 확보 기록이 있으며 무료 운영 업로드·정기 백업 체계 완료와는 구별한다.
- Resend `notify.medihelpers.co.kr` 발송 도메인 인증과 Cloudflare 비밀 설정 등록을 완료했다. 승인받은 운영자 테스트 메일 1건의 전달·실제 수신을 확인했다. 기존 Daum 수신 MX/SPF는 유지했다.
- 반입 전후 DB 백업과 원격 데이터 대사를 수행했다. 반입 후 서버 백업을 로컬에서 역변환해 반입 전 모든 테이블 행과 일치함을 확인했다.
- 기존 랭크업 사이트·호스팅·DB·파일·PG 키를 삭제하거나 해지하지 않았다.

## 남은 작업과 다음 순서

1. 이니시스 관리자 재로그인 후 기존 거래번호·금액·상태를 확보해 새 서버 조회 결과와 대조한다. 기존 MID `UPmedihelp`와 등록된 키를 유지하며 불필요한 키 재발급을 하지 않는다.
2. INIAPI `clientIp` 처리 방식을 확정한다. 가맹점 IP 별도 등록이 불필요하다는 공식 안내와 API의 요청 서버 IP 필수값은 별개다. 임의의 랭크업 IP·방문자 IP로 대체하지 않는다.
3. 거래 대상과 금액을 정해 실제 카드 승인·취소 시험, 주문·PG·권리 회수 대사를 진행한다. 카드 입력 등 필요한 사용자 단계에서 인계한다.
4. 기존 회원의 정상/정지/탈퇴 상태와 로그인 후보, 실제 재설정 흐름을 검증하고 활성화한다. 확인 없이 보류를 일괄 해제하지 않는다.
5. 공고 소유자 미확인 1건, 기존 결제 소유자 미확인 28건 및 잔여 열람권 사용량 등 예외를 대사한다. 이메일만으로 소유자를 연결하지 않는다.
6. 기존 유료 광고의 실제 권리·기간을 확인한 뒤 공개한다. 새 결제나 환불을 한 것처럼 거래를 생성하지 않는다.
7. 무료 한도 안의 업로드·정기 백업 경로와 복구를 검증한다. R2 구독·유료 업그레이드는 승인된 범위가 아니다.
8. 최종 증분·진행 중 구 주문 콜백·HTTPS·메일 링크·결제 리턴·롤백 경로 검증 후 www/apex를 새 서비스에 연결한다.

현재 정식 홈페이지 전환은 미완료다. 네임서버는 Cloudflare이지만 www/apex A 레코드는 랭크업 `121.254.171.115`를 유지한다. ‘몇 시간/1~2일’ 예상은 외부 확인과 사용자 카드 시험 등이 순조롭다는 조건의 추정이며 완료 약속이 아니다.
