# 병원 가입 인증·의료인 연락처 보호 업데이트

기준일: 2026-08-15

## 의료인 연락처 공개 원칙

- 의료인은 이력서·구직글을 등록할 때 연락처를 `비공개` 또는 `열람권 보유 병원에 공개`로 직접 선택합니다.
- 기본값은 `비공개`입니다.
- `비공개`를 선택하면 병원이 이력서 열람권을 구매해도 성명·전화번호·이메일을 받을 수 없습니다. 열람권은 경력과 상세 이력 확인 권한일 뿐 연락처 공개 동의를 대신하지 않습니다.
- 연락처 공개 여부는 서버의 `GET /api/talent-detail/:id` 응답에서 최종 판정합니다. 화면에서만 가리는 방식이 아니며, 중첩된 상세 JSON에서도 연락처 사본을 제거합니다.
- 본인과 관리자는 운영·권리행사를 위해 원본을 확인할 수 있습니다. 병원에는 의료인이 선택한 범위만 제공합니다.

## 병원 회원가입 인증 흐름

1. 병원 담당자가 병원명, 대표자명, 사업자등록번호, 주소와 사업자등록증 PDF·이미지를 제출합니다.
2. 서버는 PDF/JPEG/PNG/WEBP 형식, 파일 서명과 10MB 제한을 검사합니다.
3. 서류 원본은 기존 비공개 R2 바인딩에 저장하고, D1에는 검토 상태·파일 키·크기·SHA-256 등 최소 메타데이터를 기록합니다.
4. 병원 계정은 `pending` 상태로 생성되며 세션을 발급하지 않습니다. 승인 전 로그인과 병원 기능 사용은 차단됩니다.
5. 관리자 계정에 내부 알림이 생성되고, 메일 발송 환경 변수가 설정된 경우 관리자 메일에도 검토 요청이 전달됩니다.
6. 관리자는 콘솔에서 서류를 열어 승인 또는 반려합니다. 결과와 사유, 처리자, 시각은 감사 이력에 남고 신청자에게 알림·메일을 보냅니다.
7. `verification_status=verified`인 승인 완료 병원만 로그인하고 공고 상품을 신청할 수 있습니다. 과거 데이터의 `unverified`, 승인 대기 `pending`, 반려 `rejected`는 모두 차단하며 반려 시 재검토 안내를 표시합니다.

이번 승인 기능은 병원 가입 신원 확인에만 적용합니다. 공고·결제·일반 콘텐츠를 사전 승인 방식으로 되돌리지 않습니다.

## 보관·접근 기준

- 사업자등록증 원본 URL을 공개하지 않으며 관리자 인증을 통과한 전용 API로만 내려줍니다.
- 현재 구현 보관 기준은 제출일부터 3년이며, 정식 운영 전 개인정보처리방침과 실제 업무상 필요 기간을 법률 검토해 확정해야 합니다.
- 거절·탈퇴·보관기간 만료 시 원본 삭제와 D1 메타데이터 파기 작업을 운영 절차로 연결해야 합니다.
