## 재현과 수정 후보

실제 검수본 로그인 화면의 ‘비밀번호를 잊으셨나요?’ 링크가 `/account/recovery`로 연결되어 아이디 찾기가 기본 표시됐다. AccountPage의 해당 링크에 `?mode=password`를 추가했다. 기존 복구 화면이 지원하는 모드를 사용하며 비밀번호 처리·인증·메일 API는 변경하지 않았다. 아이디 찾기 링크는 유지했다.

로컬 빌드의 새 URL에서 비밀번호 재설정 제목과 이메일/기존 아이디 입력을 확인했다. 정적 미리보기에는 계정 API가 없어 로그인 화면 전체 진입 흐름은 검증하지 못했다. 실제 비밀번호 설정·메일 발송을 수행하지 않았다.
