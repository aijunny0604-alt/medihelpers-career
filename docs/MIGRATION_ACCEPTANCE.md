## 최신 실측 근거

10월 9일 검수 D1을 새로 export하고 보존 상태를 다시 확인했다. 47개 테이블, 4,727,830바이트, 무결성 정상, 외래키 오류 0. SHA-256 `813ee0b8d2cc49b5955bef02c547562c9420ea71587243ee89db9a2879fcc1ca`로 10월 3일 정상 백업과 동일하다. 개인정보 원본은 Git 밖 감사 폴더의 `medihelpers-20261009-064823-61be016c.sql`에 보관했다.

새 백업에서 보관 원문 1,205건의 SHA-256을 각각 다시 계산해 불일치 0건을 확인했다. 기존 로그인 별칭 281개가 서로 다른 281계정에 연결되고, 없는 계정을 가리키는 별칭은 0개다. 의료인 130·병원 151계정 모두 보호 보류 상태이며, 공고 127건은 관리자 전용 초안이다. 이는 확보 자료의 보존 검사이지 랭크업 전체 원본의 완전성 검사가 아니다.

증거: 비공개 `medihelpers-20261009-064823-61be016c.verified.json`, `migration-preservation-batch-20261009.json`. 원격 쓰기·권리 발급·메일 발송 없이 검사했다. 운영 계정 1개를 포함한 accounts 총수 282를 기존 회원 282명으로 오인하지 않는다.
