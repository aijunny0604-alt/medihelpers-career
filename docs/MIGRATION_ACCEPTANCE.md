# 회원·결제 이전 인수 검수표

작성일: 2026-09-24 · 전체 항목 미검수. 실제 원본 수령 및 리허설 후 채운다.

## 자료 인수 기록

추출 담당 / 추출시각·시간대 / 동결 여부 / DB 종류·버전·문자셋 / 테이블 설명 / 파일 저장 규칙 / 보호 저장 위치 / SHA-256 / 바이트 수 / 접근 담당 / 폐기 기준을 기록한다. 원본을 읽기 전용으로 보관하고 정규화·변환 결과는 별도 저장한다. 원본이나 비밀번호·PG 키는 Git/채팅/공개 로그에 넣지 않는다.

읽기 전용 도구 `node scripts/migration-preflight.mjs <정규화 JSON>`는 일부 구조 오류를 찾는다. 종료코드 0도 이전 승인이나 실제 이전 완료가 아니다. 원본 SQL 집계와 변환 후 DB 집계를 독립적으로 대사한다. 총합이 같아도 회원별 지급이 뒤바뀔 수 있으므로 개별 소유권/금액/권리도 전수 비교한다.

## 반드시 시험할 회원 사례

- 정상 의료인·병원 각각: 기존 로그인/재설정, 본인 자료만 조회·수정, 이름·연락처 원본 확인.
- 이메일 누락·중복·예전 아이디 로그인: 회원 보존, 별도 본인 확인, 다른 사람 계정과 병합 금지.
- 정지·탈퇴·관리자 등급: 자동 활성화·관리자 승격 금지, 보존 대상과 삭제 대상 분리.
- 비밀번호 호환 불가: 만료·1회용 재설정 링크 실제 수신, 반복·만료 토큰 거절, 새 세션 권한 확인.
- 연락처 비공개·동의 철회: 열람권 구매 후에도 연락처 비공개, 목록/상세/API/첨부 우회 노출 없음.
- 5개월 비활성 구직글: 기준 시각·기존 날짜 적용 정책 확인, 외부 비공개·본인 조회·재공개 가능.
- 신규 필수정보 누락 회원: 보완 절차와 가입정보 수정 잠금의 충돌 없음.

| 위변조 금액/MID/타인 주문 접근 | 서버 거부, 권리 변경 없음 | 미검수 |

테스트 MID 검증과 실제 MID의 승인·취소 검증은 별도로 기록한다. 실제 금액 결제/취소는 대상·금액·수단이 정해진 명시적 승인 후 실행한다. 가상 환불 성공을 실제 환불 성공으로 기록하지 않는다.
