## 재현 및 수정

1. **관심공고 중복 요청:** 기존 API는 요청마다 반전했다. 같은 저장 요청을 두 번 받으면 해제되고, 해제 요청 재전송은 다시 저장했다. 생성 Cloudflare Worker와 격리 DB에서 재현했다. 새 화면은 원하는 상태를 명시하며 서버는 중복 INSERT를 무시하고 동일 상태를 유지한다. 잘못된 상태 타입은 400으로 거부한다. 이전 화면의 상태 없는 토글 요청은 호환용으로 유지한다.
2. **늦은 응답·회원 전환:** 기존 화면은 공통 localStorage에 회원 목록을 저장해 로그아웃·다른 계정 로딩 중 이전 찜 상태가 보일 수 있었다. 이제 회원 목록은 서버에서 읽고 메모리에만 보관한다. 비회원 키는 별도로 분리한다. 초기 조회 전 클릭은 조회를 기다리고, 같은 공고 변경은 순서대로 전송하며 오래된 응답으로 새 선택을 덮지 않는다. 전환·이탈한 화면의 대기 요청과 응답은 폐기한다.
3. **잘못된 상세 주소:** 불완전한 `%` 인코딩이 서버 500 오류 또는 화면 디코딩 예외를 일으켰다. 잘못된 경로는 400 안내로 처리하고 화면에서도 안전하게 판별한다. 정상적인 한글·퍼센트 인코딩은 한 번만 디코딩한다.
4. **존재하지 않는 마이페이지 탭:** `?tab=invalid-tab`은 메뉴만 남고 본문이 비었다. 기본 ‘내 활동 요약’을 표시하도록 보완했다.
5. **찜 버튼 접근성:** 이미 저장해도 버튼 이름이 ‘관심 공고 저장’이었다. 저장·해제 명칭과 `aria-pressed`를 현재 상태에 맞춘다.

같은 공통 처리에 남아 있던 인재 관심 목록 컴포넌트와 로컬 개발 mock도 API 계약에 맞췄다. 이 인재 컴포넌트는 현재 정식 라우터에 직접 연결되지 않아 ‘현재 사용자 화면에서 재현한 장애’로 세지 않는다. 시작 시 문자열 배열을 객체 배열로 잘못 해석하던 불필요한 사전 조회도 제거했다. 비회원은 관심 목록 서버 요청을 보내지 않는다.
