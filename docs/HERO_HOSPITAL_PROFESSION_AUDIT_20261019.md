# 메인 영상·병원 가입·의료 직군 검수 (2026-10-19)

## 상태

- 기준 소스: GitHub `agent/medihelpers-ui-stability`, 직전 수정 `09abb62`에서 계속 작업.
- 정식 도메인 `https://www.medihelpers.co.kr/`에는 아직 배포하지 않았다. 현재 PC에 Cloudflare 운영 인증이 없다.
- Sites `main`은 소스 미러이며 옛 Sites 주소에 대신 배포하지 않는다.
- 기존 회원 원본 대조와 비밀번호 호환 이관은 사용자가 나중에 진행하기로 했다.
- 사용자가 면허 확인은 하지 말라고 명시했다. 면허 제출·확인·가입 승인 절차를 추가하지 않는다.

## 메인 타이틀 영상

기존 `HeroMedia`는 1025px 이상이며 동작 줄이기와 데이터 절약이 모두 꺼진 경우에만 video 요소를 만들었다. 따라서 모바일 또는 해당 설정을 켠 PC에서는 포스터만 보였다.

모든 화면 크기에서 영상을 만들고 `autoPlay`, `muted`, `loop`, `playsInline`, `preload=auto`를 적용했다. 첫 자동재생 제한 시 미디어 준비 완료·탭 복귀·사용자의 터치/키 입력에서 재시도한다. 다른 UI의 동작 줄이기 설정은 유지한다.

격리 브라우저에서 PC 1280px와 모바일 390px 모두 `paused=false`, `readyState=4`, 무음 재생과 재생 시간 변화를 확인했다. 모바일 가로 넘침은 없었다. OS 설정 자체를 변경해 실기기별로 시험한 것은 아니며, 해당 설정에 의존하는 코드 조건을 제거했다. 브라우저 자체의 강제 자동재생 차단이나 기기 절전 정책까지 우회한다고 보장하지 않는다.

## 병원 회원가입과 동의

- 선택 정보는 기본 접힘이며 동의하지 않아도 필수 정보와 서류로 가입된다.
- 미동의 상태의 기관 유형·담당자 직책·부서·상세주소·홈페이지·팩스는 서버가 저장에서 제외한다.
- 사업자등록증 첨부와 해당 서류 수집·이용 동의는 필수로 유지한다. 누락 시 HTTP400, 정상 필수 정보는 HTTP201을 검증했다.
- 서류 이용 목적·보관 안내와 약관 본문은 필요할 때 펼친다. 필수 체크는 본문을 펼치지 않고 할 수 있다.
- 전체 동의 문구를 `아래 필수 항목 모두 동의`로 명확히 했다. 선택 정보 동의와 서류 동의는 별도다.
- 검수 브라우저에서 카카오 주소 검색 iframe이 콘텐츠 차단 화면을 표시했다. 종전 주소란은 읽기 전용이어서 검색 불가 시 가입을 진행할 수 없었다. 주소 검색을 유지하면서 직접 입력도 가능하게 변경했다. 외부 검색 차단 원인이 모든 운영 브라우저에 동일하다고 단정하지 않는다.
- 합성 PNG 서류·직접 입력 주소로 모바일 UI 가입을 수행하여 선택 동의 미체크 상태의 가입 완료 화면과 로그인 아이디 표시를 확인했다. 실사용자나 운영 DB 자료는 사용하지 않았다.

## 의사와 다른 의료직군 구분

개인 회원의 내부 계정 role은 공통 `doctor`이며 병원은 `hospital`이다. 개인의 실제 직군은 `registrationProfile.professionType`에 별도로 저장한다. 내부 role만 보고 모든 개인을 의사로 판단하면 안 된다.

| 구분 | 가입 직군 | 공개 구직글 분류 |
| --- | --- | --- |
| 의사 직군 | 의사, 치과의사, 한의사 | `staffType=doctor` |
| 그 외 의료직군 | 간호사, 간호조무사, 방사선사, 임상병리사, 물리치료사, 작업치료사, 치과위생사, 병원 행정·원무, 기타 의료인 | `staffType=medical` |

- 가입 선택 목록을 위 두 그룹으로 나눴다. 공통 허용 목록을 클라이언트와 신규 아이디 가입 서버에서 사용한다.
- 신규 아이디 가입 시 직군 누락·목록에 없는 값은 HTTP400으로 처리한다. 종전 이메일 가입 API의 직군 생략 호환성은 유지한다.
- 가입 완료와 마이페이지에서 `의사 회원`, `간호사 회원`처럼 저장된 직군을 표시한다. 개인 공통 화면의 영문 제목도 `PERSONAL DASHBOARD`로 맞췄다.
- `본인 확인`이라는 오해 소지가 있는 공통 마이페이지 배지를 실제 상태인 `로그인됨`으로 변경했다.
- 가입 직군이 이력서 저장에서 우선한다. 요청의 profession을 반대 직군으로 바꿔도 가입 직군이 유지되는지 12개 직군 모두 검사했다.
- 각 직군의 이력서 저장 → 구직글 공개 → 게시판의 직군/분류까지 검증했다.
- 개인 면허 확인은 수행하지 않으며 신규 가입만으로 확인 완료 표시를 만들지 않는다. 가입 문구에서도 이후 면허 인증을 요구하는 안내를 정리했다.
