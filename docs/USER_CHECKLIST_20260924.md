# 메디헬퍼스 직접 확인 체크리스트 — 2026-09-24

체크박스는 사용자가 직접 확인한 뒤 표시하는 용도입니다. 구현 완료와 실제 외부 서비스 검증 완료는 구분합니다.

## 화면·공통

- [ ] 홈: 메인 소개 타이틀 → 조건 검색 → 메인 채용광고 → 베이직 공고 순서인지 확인.
- [ ] 검색: 진료과·지역·초빙 유형 선택 후 조건이 채용 목록에 적용되는지 확인. 한의사 필터도 확인.
- [ ] 일반 구인구직 상세·마이페이지: 헤드헌터 상담 유도 버튼이 없고 맞춤 헤드헌팅 페이지에서는 서비스 이용 가능.
- [ ] 마이페이지: 본인 이름 또는 병원명 표시, 큰 글씨·사이드 메뉴·넓은 본문 확인.
- [ ] 상세 뒤로가기: 눈에 띄는 버튼으로 목록 복귀하며 부드러운 스크롤 애니메이션이 없는지 확인.
- [ ] 필수 입력 누락: 큰 빨간 설명과 해당 입력의 빨간 강조 확인.
- [ ] 삭제: 사이트 자체 확인창 표시, 취소하면 그대로 유지, 확인하면 삭제 후 목록으로 이동.

## 가입·계정

- [ ] 로그인: 가입 완료 화면이 잠깐 끼어들지 않는지 확인.
- [ ] 신규 가입: 가입 완료 전용 화면과 다음 이동 버튼 확인.
- [ ] 회원정보/이력서/공고: 가입한 이름·전화·이메일·직군/병원 정보가 일관되며 임의 수정되지 않는지 확인.
- [ ] 비밀번호 변경: 현재 비밀번호 확인 → 변경 → 재로그인. 이전 로그인 세션은 종료.
- [ ] 개인정보 처리방침: 내부 기술 설명은 제거되고 실제 개인정보 처리 안내는 남아 있는지 확인.

## 의료인 이력서·구직글

- [ ] 이력서 선택·관리: 선택한 이력서의 실제 편집 화면으로 이동.
- [ ] 새 이력서: 기존 이력서를 덮어쓰지 않고 추가 저장.
- [ ] 새 구직글: 기존 글이 있어도 등록하기 버튼으로 새 글 작성. 기존 글 수정과 구분.
- [ ] 이력서 내용: 개인 초안은 저장 가능, 게시/재공개 시 직군·전문분야·지역·경력/소개 등 최소 정보 요구.
- [ ] 수정 후: 수정한 구직글 상세로 바로 이동하며 목록 게시 순서는 유지.
- [ ] 편집 하단: 취소·삭제·저장 버튼 구분, 모바일에서도 겹치지 않는지 확인.
- [ ] 연락처 공개/비공개: 의사가 선택 가능. 비공개면 목록 배지·구매 안내에 표시되고 구매 후에도 전화·이메일 비공개.
- [ ] 잠긴 이력서: 블라인드·자물쇠·열람권 구매 버튼 표시. 예시도 가상 결제로 상세 열람 테스트 가능.
- [ ] 열린 상세: 이름이 잘 보이고 의사 면허 항목은 없으며 전화·이메일은 클릭 링크가 아닌 텍스트.
- [ ] 게시 관리: 본인이 수동 비공개·재공개·삭제 가능. 비공개 글은 타인에게 숨기고 본인은 확인 가능.
- [ ] 5개월 미관리 글: 자동 비공개 처리, 본인 마이페이지에서 상태 확인 및 재공개 가능. 날짜 경계는 자동검사로 검증함.

## 병원 공고·이미지

- [ ] 공고 등록: 큰 글씨와 정돈된 배너·사진·기본정보 레이아웃 확인.
- [ ] 이미지 업로드: 선택한 사진이 즉시 미리 보이고 서로 다른 비율에서도 찌그러지지 않는지 확인.
- [ ] 공고 상세: 병원 로고와 배너가 충분히 크게 표시되는지 확인.
- [ ] 수정 후: 해당 공고 상세로 이동. 종료·비공개 공고도 본인 병원은 확인 가능하고 타인은 접근 불가.
- [ ] 내 공고: 노출 중/종료/결제 대기/환불 상태 구분. 종료 공고는 기존 내용·사진을 유지해 30일 재구매 가능.
- [ ] 재구매: 버튼 중복 클릭이나 새로고침에도 같은 대기 주문을 이어가며 중복 주문이 생성되지 않는지 확인.

## 결제·외부 연결

- [ ] 열람권 결제 화면: 넓은 배치, 불필요한 가입정보 입력칸 제거, 연락처 비공개 안내 확인.
- [ ] 가상 환불: 관리자 전액 환불 후 주문 상태·열람 권한·잔여 팩·공고 노출이 함께 반영되는지 확인.
- [ ] 실제 이메일 수신 — 미완료: Resend 발신 도메인·API 키 설정 후 아이디 안내/재설정 링크 수신 검증 필요.
- [ ] 실제 결제·실제 환불 — 미완료: PG 운영 연결 및 취소 API/부분환불/정산 검증 필요.
- [ ] 정식 오픈 전 — 미완료: 테스트 계정·예시 게시물·가상 결제 정리 및 실운영 최종 점검.
