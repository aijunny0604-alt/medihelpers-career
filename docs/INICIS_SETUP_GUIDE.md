# 이니시스 이전·설정 가이드

2026-09-24 기준. [운영 전환 준비 문서](MIGRATION_20260924.md)를 현재 기준으로 사용한다.

**키만 입력하면 실결제 운영이 완료되는 상태가 아니다.** 현재 PC 웹표준 연동 골격과 가상 결제 검증은 있지만, 모바일·보안 필수 필드·PG 리턴 검증·망취소·실제 취소/환불·대사 보완과 공급자 테스트가 남아 있다.

기존 medihelpers.co.kr 도메인과 이니시스 계약/MID를 유지하는 방향이다. 같은 도메인이라는 이유만으로 계약 확인·모듈 변경·키 확인·비용 확인이 불필요하다고 단정하지 않는다. 랭크업 호스팅 계약 여부와 새 결제 방식 지원을 가맹점관리자/담당자에게 확인한다.

- MID, PC 웹결제 signKey, 선택한 취소 API용 자격정보는 서로 용도가 다르다. signKey를 API Key/IV로 대신 사용하지 않는다.
- 키는 채팅·Git·브라우저 코드에 저장하지 않고 검증된 운영 호스팅 시크릿으로 설정한다.
- SITE_ORIGIN은 실제 결제 페이지와 동일한 HTTPS origin이어야 한다. www/apex를 먼저 통일한다.
- PAYMENT_LIVE=true는 키 누락 시 가상 승인을 막는 보호 설정이며 실제 연동 완료 인증이 아니다.
- 테스트 스크립트/테스트 MID/실 MID 구분, PC·모바일 결제·취소·망취소·중복 요청·일별 원장 대사를 모두 확인한 후 개시한다.
- 기존 거래의 취소/환불과 미입금 가상계좌 등 진행 건은 전환 시 별도 유지한다.

문의 초안과 준비물은 [업체 확인 요청서](MIGRATION_VENDOR_REQUESTS.md)에 있다. 실제 발송은 하지 않았다.
