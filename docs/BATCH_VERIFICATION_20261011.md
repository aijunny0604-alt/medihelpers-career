## 실제로 남은 검증

- 의료인·병원 계정의 실제 로그인과 소유 자료 접근: 현재 실제로 검증된 역할은 관리자다. 고객 비밀번호를 추측하거나 관리자 세션을 타 역할로 바꾸지 않았다.
- 회원 상태·전체 게시물/첨부·유료권리 최종 대조: 원본 DB 문제와 함께 사용자 요청으로 보류 중이다.
- 운영 설정으로 가입·글쓰기·메일 실사용: 현재 read-only/가입 차단/점검 설정이므로 통과로 판정할 수 없다. 기존 수신 확인과 로컬 합성 검사는 별도 증거다.
- 실제 카드 승인·수동 환불·권리 회수: 사용자가 추후 직접 시험하기로 했다. 수행하지 않았다.
