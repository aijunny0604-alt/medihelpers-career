# 새 홈페이지 출시 실행표 — 2026-10-17

## 현재 결정

FTP 접근과 랭크업 전체 파일 백업은 사용자 요청으로 보류한다. 새 홈페이지는 Cloudflare 독립 운영을 목표로 한다. 랭크업 호스팅·웹 연결·기존 결제는 보존한다. FTP 보류를 완전한 백업 또는 구 결제 검증 완료로 해석하지 않는다.

## FTP 없이 계속할 순서

1. 현재 검수 환경에서 발견되는 실제 제품 오류와 운영 안내를 수정한다. 증거 없이 기능을 바꾸거나 테스트를 반복하지 않는다.
2. 운영자 계정으로 공개 콘텐츠·문의·수동 환불 관리 화면을 검수한다. 실제 환불/유료 권리 변경은 실행하지 않는다.
3. 공개할 기능, 가입·결제 차단 유지 여부, 기존 회원 보류 안내 및 법률 문서 검토 상태를 확정한다. draft/noindex 후보를 정식 서비스 완료로 표시하지 않는다.
4. 실제 전환 직전 기존 주문을 정리하는 방식 또는 검증된 콜백 유지 방식을 확정한다. FTP 원본이 없어도 주문 정리 방법을 선택할 수 있으나, 선택/실행 여부를 자동으로 가정하지 않는다.
5. 최신 DNS·두 DB·Worker 버전을 보존하고 도메인 전환을 수행한다. 사용자에게서 현재 전환 제한을 해제하는 지시가 있기 전에는 이 단계를 실행하지 않는다.
6. 정식 주소의 TLS/이전 링크/실제 로그인/메일을 확인한다. 복구 시 신규 데이터 차이를 보존한다. DNS 복귀만으로 데이터가 역이전되는 것은 아니다.

## 보존 및 변경 이력

- 랭크업 FTP 연결을 위한 현재 PC IP를 사용자 승인으로 추가했고 기존 IP는 유지했다. 비밀번호 인증은 실패했으며 원본 파일 조회·변경·백업은 하지 못했다. 이 접근 허용을 새 사이트의 운영 의존성으로 사용하지 않는다.
- 랭크업 회원 이메일은 설치메일 수신 후 사용자 직접 저장으로 기존 한메일 주소에 복원했다. 회원정보 화면을 다시 열어 저장값을 확인했다. 주소/접속 비밀값은 Git 문서에 기록하지 않는다.
- 기존 대표 도메인·메일 DNS·PG 키·랭크업 파일은 이번 준비 작업에서 변경하지 않는다.
