# 병원·의료인 직접 메시지 기능 종료 (2026-09-05)

## 현재 정책

- 병원 회원과 의료인 회원이 서로 직접 메시지를 보내는 기능은 제공하지 않습니다.
- 지원·문의 상세 화면에는 직접 답장 입력창과 회원 간 대화 내역을 표시하지 않습니다.
- 직접 메시지 API 요청은 서버에서 거절합니다.
- 병원 및 의사의 문의는 마이페이지의 헤드헌터 상담 기능으로 관리자에게 전달합니다.

## 개인정보 및 보존

- 과거 `inquiry_messages` 원장은 감사와 분쟁 대응을 위해 DB에 보존하되 회원 화면에는 노출하지 않습니다.
- 과거 `inquiry_reply` 알림과 활동 기록도 회원 화면에서 제외합니다.
- 회원 탈퇴 시 기존 정책에 따라 해당 회원의 과거 메시지 기록을 삭제합니다.
- 기존 Sites 프로젝트, D1 바인딩, R2 바인딩은 변경하지 않습니다.
