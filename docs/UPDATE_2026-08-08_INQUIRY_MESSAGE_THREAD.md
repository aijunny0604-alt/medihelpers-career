# 알림 메시지 상세 연결 개선 (2026-08-08)

## 변경 사항

- 알림에서 문의 상세로 이동했을 때 실제 수신 메시지 본문을 대화 영역에 표시합니다.
- 기존 `inquiry_reply` 알림에 저장된 메시지도 문의번호로 연결해 과거 알림을 복원합니다.
- 앞으로 주고받는 메시지는 `inquiry_messages` 원장에 발신자·수신자·시간과 함께 영구 저장합니다.
- 발신 메시지와 수신 메시지를 구분한 말풍선 UI로 시간순 표시합니다.
- 메시지를 보낸 직후 새로고침하지 않아도 대화 목록에 즉시 추가합니다.

## 개인정보 및 보존

- 로그인 계정이 발신자 또는 수신자인 메시지만 조회합니다.
- 회원 탈퇴 시 해당 회원이 주고받은 문의 메시지도 삭제 대상에 포함합니다.
- 기존 Sites 프로젝트, D1 바인딩, R2 바인딩은 변경하지 않습니다.
