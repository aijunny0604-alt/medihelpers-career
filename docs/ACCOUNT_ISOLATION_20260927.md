## 이번 구현: 연락 이메일과 계정 소유권 분리

기존 회원 중 13개 이메일 그룹의 36계정을 임의로 병합하지 않는다. DB 0020의 `account_contact_identities`에 실제 연락 이메일을 보존하고, 로그인 자격증명에는 계정별 고유 principal을 사용한다. 기존 회원은 정확한 기존 아이디로 로그인한다. 세션에서 조회한 계정 ID와 저장된 user_key만 데이터 소유권 판단에 사용한다. 내부 principal은 회원 응답의 identity에 노출하지 않는다.

- 이력서·구직글·상담·병원 지원·주문·광고·열람권은 각각 소유 계정으로 분리한다.
- 같은 이메일을 관리자와 공유해도 관리자 권한을 얻지 않는다.
- 공유 이메일만 입력한 비밀번호 재설정은 임의 계정을 선택하지 않는다. 기존 아이디를 입력하면 해당 계정의 실제 연락 이메일로 안내한다.
- 정지 계정은 이미 발급된 세션으로도 보호 API에 접근할 수 없다.
- 백업과 탈퇴 정리에 새 연락 이메일 테이블을 포함한다.

이 스키마 변경 자체는 실제 회원을 활성화하거나 기존 공고의 권리를 부여하지 않는다. 실제 기존 자격증명 후보의 로그인 검증과 소유권 연결은 별도 진행 사항이다.

작업 시작 소스 `4998d46f`는 GitHub/Sites 미러 모두 0/0 확인. 이번 변경은 아직 미배포 후보이며 DB 0020도 원격에 적용하지 않은 상태로 작성했다. 배포 시 후속 결과를 기록한다.

## 메일 설정

사용자가 Resend 무료 계정을 개설했다. `notify.medihelpers.co.kr`을 Tokyo 리전에 등록하고 DKIM TXT 1개, 발송 CNAME 2개를 Cloudflare에 추가했다. Resend에서 2026-09-27 15:56 인증 완료 표시와 공용 DNS 응답을 확인했다. 기존 Daum MX와 SPF, 기존 웹사이트 IP는 유지했다.

발송 전용(Sending access)·해당 도메인 한정 API 키 생성 화면을 준비했다. 키 생성은 사용자에게 인계했으며 이 기록 시점에는 키 등록과 실제 메일 발송은 미완료다. 키 값은 문서/저장소에 보관하지 않는다. 무료 한도 내 사용하며 유료 업그레이드는 하지 않는다.
