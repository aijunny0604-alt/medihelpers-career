## 다른 PC·브라우저 사용 원칙

- 계정, 비밀번호 해시, 역할과 세션은 공용 D1에 저장되어 같은 이메일·비밀번호로 다른 PC에서 로그인할 수 있습니다.
- 각 PC·브라우저는 독립 세션을 사용합니다. 한 PC에서 로그아웃해도 다른 PC의 정상 세션은 유지됩니다.
- 보안 쿠키를 차단하는 브라우저는 같은 출처의 `/api/` 요청에만 붙는 탭 단위 보조 세션을 사용합니다. 이 경우 탭을 닫으면 다시 로그인해야 할 수 있습니다.
- 정식 출시 전 실제 운영 대상 Chrome·Edge·모바일에서 회원가입 → 새 기기 로그인 → 역할별 기능의 최종 실기기 스모크 테스트를 한 번 더 수행합니다.
