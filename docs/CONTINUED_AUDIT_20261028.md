랭크업 원본 서버 접근이 없어 남아 있는 댓글 실패 오인·쿠키 속성·아이콘 403, 기존 실회원 비밀번호 이전 및 실카드 승인·환불은 이전 문서의 제한을 유지한다. 새 사이트 격리 검사가 통과했다고 기존 랭크업까지 완벽하거나 운영에 최신 변경이 반영됐다고 판단하지 않는다.

소스는 GitHub 작업 브랜치와 Sites `main`에 같은 커밋으로 보관한다. Sites 공개 버전 378과 기존 랭크업 운영 연결을 유지한다. 별도 QA Worker에도 배포하지 않는다.
