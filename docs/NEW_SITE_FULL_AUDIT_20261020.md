# 새 사이트 회원가입·로그인·공고·결제 전수점검

기준일: **2026-10-20**. 시작 소스 `d947fa5a6ea604bfd71c06cbcf869bda0e575c22`는 GitHub 기준 브랜치와 Sites 소스 미러가 일치했으며 앞뒤 차이는 0이었다. 이번 작업은 **새 사이트의 소스 개선과 격리 검수이며 공개 미배포**다. 기존 랭크업, 정식 도메인, DNS, Workers Route, 운영 DB와 PG 설정에는 쓰기 작업을 하지 않았다.

주문 요청의 시간 초과는 서버에서 주문이 취소되었다는 의미가 아니다. 서버 승인 없이 성공으로 표시하지 않으며 금액·서명·주문 소유권 검증을 변경하지 않았다. 주문번호가 없는 상태의 안내는 현재 화면에서의 중복 요청을 막는 장치이며, 서버 주문 생성의 전역 멱등성 보장을 추가한 것은 아니다.

가입 선택 동의는 계속 선택 사항이다. 의사·치과의사·한의사와 다른 의료 직군 구분을 유지하며 의사 면허 확인을 추가하지 않았다.

변경 코드: `src/AccountPage.jsx`, `src/formFocus.js`, `src/inicisPay.js`, `src/paymentApi.js`, `src/PaymentRecoveryPanel.jsx`, `src/main.jsx`. `src/basePath.js`는 브라우저 외 검사에서도 기본 경로를 안전하게 읽도록 보완했다.

## 검수 한계와 운영 보존

- 이번 브라우저 검수는 기존 로컬 오류 탭의 reload가 URL 보안 정책에 차단되어 진행하지 못했다. 우회하지 않았으며 수정 후 실제 화면·클릭·포커스 동작은 미확인이다. 이전 [검색·모바일 화면 검사](NEW_SITE_IMPROVEMENTS_20261020.md)를 이번 수정의 화면 검증으로 계산하지 않았다.
- 실제 카드 승인·취소, 실기기 앱카드 전환, 운영 메일/SMS 발송, 기존 실회원 비밀번호 인증은 미검증이다.
- 이전 로그인 200개는 합성 암호·회원으로 검증한 새 코드의 동작이다. 실제 랭크업 회원 이전 완료나 실제 구 사이트 정상화를 뜻하지 않는다. 원본 회원 암호 이관은 사용자 요청대로 보류한다.
- 원격 쓰기는 검증된 소스의 GitHub 기준 브랜치·Sites 미러 보관으로 한정한다. 소스 미러는 자동 게시를 끈 상태로 유지하고 새 사이트를 정식 도메인에 연결하지 않는다.
- 기존 랭크업의 최신 실서비스 정상 여부를 이번 검사로 다시 확인한 것은 아니다. 과거 복구·미검증 항목은 [현재 운영 기록](OPERATIONS_CURRENT.md)과 [랭크업 후속 기록](RANKUP_REPAIR_20261019.md)을 따른다.
