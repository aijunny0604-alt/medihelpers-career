## 복귀 원칙

기존 랭크업 호스팅·파일·DB는 삭제하거나 해지하지 않는다. 웹 전환 후 복귀하려면 신규 쓰기를 중단하고 변경분을 백업한 뒤 Worker의 www/apex Custom Domain 연결을 해제하고 원래 A/DNS-only 값을 복원한다. rollback 설정 배포만으로 DNS 복원 완료라고 판단하지 않는다. 메일 DNS는 유지한다.

DNS 캐시로 복귀에는 시간이 걸릴 수 있다. 신규 데이터는 자동으로 랭크업에 역이전되지 않는다. FTP 전체 백업은 사용자 보류로 미확보이므로 랭크업 서버 자체 장애까지 포함하는 무손실 복구를 보장하지 않는다.

기존 결제 통보 경로 또는 미처리 거래 부재를 확인하기 전 도메인 전환은 미완료로 유지한다. 남은 조건은 [주문/전환 실행서](ORDER_AND_DOMAIN_CUTOVER_20261017.md)를 따른다.
