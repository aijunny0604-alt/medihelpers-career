2. 기존 회원의 실제 로그인, 회원별 보유 권리, 게시/수정, 메일 발송 및 실제 PG 승인·취소는 별도 검수. 읽기 화면 정상만으로 전체 거래 정상화로 보고하지 않음.
3. 신규 데이터 역이전과 랭크업 FTP/전체 DB 백업은 미완료. 사용자 보류한 기존 회원의 신규 사이트 이관을 임의 재개하지 않음.

오늘 변경과 복귀 증거는 [작업일지](WORKLOG_20261019.md), [복구 결과](RANKUP_RESTORE_20261019.md), [복구 실행서](ROLLBACK_RUNBOOK.md)를 따른다. 신규 앱의 당시 검수 결과는 [검색·조회 배포 기록](SEARCH_LOADING_RELEASE_20261019.md), 복귀 직전 운영 이력은 [보관 문서](OPERATIONS_PRE_RESTORE_20261019.md)에 남긴다.
