# 2026-10-10 이전 공고 지역 필터 수정

기존 변환은 region/primary만 사용해 location만 존재하는 이전 광고4건을 모두 전국으로 분류했다. 따라서 인천·경남·강원을 선택하면 해당 공고가 누락됐다.

명시적 region은 보존하며, primary 또는 location의 첫 행정구역 토큰이 확인되는 경우에만 표준지역으로 연결한다. 강원특별자치도/경상남도 등 정식 명칭도 지원한다. 서울병원 같은 상호로 지역을 추측하지 않고 명시된 전국을 주소로 덮어쓰지 않는다. 주소 본문과 원격DB는 변경하지 않는다. 진료과 추정이나 회원권한 변경도 없다.

실제 공개 응답 스냅샷은 인천1·경남2·강원1로 검증했다. 합성 단위448개 포함 전체18묶음1,622개 및 일반/Cloudflare 빌드 통과. 기존 원문/명시지역/불명확주소/프로토타입 속성명 입력 보존·처리를 검증했다. 실제 배포와 브라우저 필터 결과는 후속 기록한다.

증거: Git밖 region-filter-tests-20261010.log 및 기존 public-ads-api-20261010-private.json. 테스트는 실제 역할 로그인/실카드 결제를 대체하지 않는다.
