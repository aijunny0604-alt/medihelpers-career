## 핵심 사용자 흐름

### 의료인 이력서와 구직글

1. `/resume`에서 이력서를 작성하거나 수정합니다.
2. 이력서는 항상 개인 문서로 저장되며 저장만으로 게시판에 올라가지 않습니다.
3. `/job-seeker-posts/new`에서 저장된 본인 이력서 하나를 선택합니다.
4. 구직글 제목, 진료과·직군, 희망 지역, 입사 가능 시점, 근무 형태와 소개를 별도로 작성합니다.
5. 연락처는 구직글마다 `비공개` 또는 `열람권 구매 병원에 공개`를 선택합니다.
6. 이력서가 없으면 먼저 이력서를 작성하고 완료 후 구직글 작성 화면으로 돌아옵니다.

연락처 비공개를 선택하면 병원이 열람권을 구매해도 전화번호와 이메일을 확인할 수 없습니다. 공개 인재 목록은 활성 구직글만 읽고 개인 이력서 저장 상태를 공개 조건으로 사용하지 않습니다.

### 관리자 이력서 확인

- 관리자 콘솔 `이력서 기록`에서 이력서 행을 누르면 성함, 직군, 전문분야, 전화번호, 이메일, 희망 지역·보수, 현재 지역과 경력·자기소개를 확인할 수 있습니다.
- 의사가 마이페이지에서 헤드헌터에게 이력서를 첨부한 상담 기록도 원시 `resumeSnapshot` JSON 대신 같은 형식의 상세 항목으로 표시합니다.
- 관리자 기능은 DB 기록 읽기 전용이며 사용자 이력서를 수정하거나 삭제하지 않습니다.

## 회원·권한 기준

- 회원 유형은 가입 시 DB에 저장되고 로그인 시 자동 분류합니다. 로그인 화면에서 역할을 다시 선택하지 않습니다.
- 의료인 구직글 작성은 `doctor` 계정만 허용합니다.
- 로그아웃·병원·관리자 상태에서 의료인 전용 주소를 열면 로그인·가입 유도 버튼 없이 안내, 뒤로가기와 홈 버튼만 표시합니다.
- 병원 회원가입은 사업자등록증을 비공개 제출 이력으로 보관하지만 관리자 승인 대기 없이 즉시 완료됩니다.
- 병원 유료 광고는 로그인한 병원 계정만 등록·수정할 수 있고 직접 삭제는 허용하지 않습니다.

## 지원·상담 전달 기준

- 병원 유료 채용공고 직접 지원은 해당 공고를 등록한 병원 채용담당자에게 전달됩니다.
- 맞춤 헤드헌팅 게시글 문의만 담당 의사 헤드헌터에게 전달됩니다.
- 의사 회원은 마이페이지에서 저장 이력서를 첨부해 헤드헌터에게 구직 상담을 보낼 수 있습니다.
