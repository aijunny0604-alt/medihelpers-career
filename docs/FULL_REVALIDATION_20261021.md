## 남은 문제와 미검증

1. 랭크업 댓글 수정 JS는 응답 상태 0·204를 성공으로 오인한다. 오늘 운영 JS를 받아 5상황 중 2상황에서 다시 재현했다. 원본 서버 접근 권한이 없어 이전 수정 후보는 미적용이다.
2. 랭크업 일부 세션 쿠키에 Secure/HttpOnly/SameSite 속성이 없다. 서버 설정 수정이 필요하다.
3. 랭크업 `/rankup_module/images/ic_dot1.gif`는 403이다. 원본 파일/권한 점검이 필요하다.
4. 실회원 로그인, 실제 카드 승인·환불, 운영 PHP의 저장·SMTP 실패 처리는 검수 계정·서버 접근 없이 검증할 수 없다. 관리자 재로그인을 지금 하기 어렵다는 사용자 상황을 유지한다.
5. 비활성 `RecruitmentCrmPage`, `ConsultationAdminPage`, `JobPostBoardPage`에는 저장 실패 처리 문제가 남아 있다. 21개 격리 상황으로 확인했지만 현재 import/렌더 경로가 없고 해당 URL은 조회 전용 AdminConsole로 연결된다. 서버 쓰기도 405이다. 현재 사용자 결함으로 집계하지 않았으며 재활성화 전에 수정해야 한다.
6. 기존 회원 비밀번호의 원본 검증 방식·자료 대조 및 일괄 이전은 보류 상태다. 합성 이전 테스트 통과가 원본 회원 이전 완료를 뜻하지 않는다.
