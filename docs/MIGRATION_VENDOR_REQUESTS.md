# 랭크업·이니시스 확인 요청 초안

아래는 사용자 검토용 초안이며 업체에 발송하지 않았습니다. 비밀번호나 키를 일반 메일/채팅으로 요청하지 않습니다.

## 2026-10-03 이니시스 확인용 최종 초안

수신: KG이니시스 기술지원 `ts@kggroup.co.kr` ([공식 안내](https://www.inicis.com/blog/archives/category/support?post_id=3307)).

제목: [메디헬퍼스 UPmedihelp] 기존 MID 유지 및 Cloudflare Workers INIAPI clientIp 문의

안녕하세요. 메디헬퍼스(medihelpers.co.kr) 기존 상점 MID UPmedihelp의 홈페이지 이전을 준비 중입니다. 사업자와 대표 도메인은 유지하고, 기존 랭크업 사이트는 복구 및 과거 거래 관리용으로 보존합니다. 가맹점관리자에서 상점그룹 HOSTrankup을 확인했습니다. 아래 사항을 확인 부탁드립니다.

1. 기존 MID·계약·웹결제 Sign Key를 유지하면서 자체 개발한 Cloudflare Workers 사이트에서 PC 웹표준 결제, 모바일 결제 및 INIAPI 거래조회/카드 전액 취소를 사용할 수 있나요? 필요한 변경 신청이나 추가 비용이 있으면 안내 부탁드립니다. 계약 변경이나 추가 서비스 신청을 요청하는 문의는 아닙니다.
2. Workers 환경은 요청 서버의 고정 IPv4를 직접 제공하지 않습니다. 공식 API의 필수 clientIp(가맹점 요청 서버 IP)에는 어떤 값을 사용해야 하나요? Workers의 TLS 소켓 연결 자체는 성공했지만 SocketInfo.localAddress는 제공되지 않았습니다. 방문자 IP나 기존 랭크업 서버 IP를 임의로 사용하지 않고 권장 방식을 확인하려 합니다. V2 거래조회와 V1 카드 전액 취소에 적용할 방법 및 고정 송신 IP 중계 서버 필요 여부를 알려주세요.
3. 기존 사이트 결제를 유지한 채 신규 사이트를 검증할 때 테스트 MID/환경, 검수 URL 및 승인·전액 취소 시험에 필요한 절차를 안내 부탁드립니다. 가맹점관리자에 취소한도금액이 0원으로 보이는데, 신규 소액 승인 후 당일 전액 취소 시험에 영향을 주는지도 확인 부탁드립니다.

현재 정식 도메인은 기존 랭크업에 연결되어 있고 신규 사이트 실결제는 차단 중입니다. 키·카드정보·고객 개인정보는 첨부하지 않았습니다. 기존 계약과 키를 변경하거나 재발급하지 말고 위 사항을 안내해 주시면 감사하겠습니다.

발송 상태: 2026-10-03 사용자가 직접 조사·진행을 요청하여 문의 발송 보류, 미발송. 공개 매뉴얼의 시험 거래로 Workers 통신을 검증했으며 결과와 운영 미확정 범위는 PAYMENT_RECONCILIATION_20261003.md에 기록했다.

## 랭크업

medihelpers.co.kr을 새 시스템으로 이전하려고 합니다. 기존 회원을 최대한 유지하고 공고·이력서·결제 및 잔여 유료 권리를 검증해 이전할 예정입니다. 아래 제공 범위와 방법·비용·소요기간을 확인 부탁드립니다.

- 전체 DB 백업(SQL), DB 버전/문자셋/타임존, 테이블·컬럼/회원등급/상태 코드 설명
- 회원 아이디·회원번호·이메일·연락처·병원정보·가입/탈퇴/정지 상태 및 약관/공개/마케팅 동의 증거
- 비밀번호 저장 알고리즘, salt/반복수/인코딩 설명(평문 비밀번호 불필요)
- 공고·이력서·지원·첨부파일 전체 백업과 원래 URL/소유 회원번호 매핑
- 주문·이니시스 TID·승인/취소/환불·미결제 내역, 상품별 만료일/잔여 횟수/열람 권리
- 백업 기준 시각·테이블별 건수·파일 목록/체크섬, 최종 증분 추출 방법
- 쓰기/결제 일시 중지, 이전 후 기존 관리자 조회·과거 거래 환불 유지, 호스팅 종료 시점
- DNS/도메인 관리 주체와 전체 레코드 백업, 기존 메일 유지 방법
- 부동산/게시판 등 새 사이트에 없는 자료의 백업 범위

원본 자료는 접근 제한 다운로드 또는 암호화 전달 방식으로 부탁드립니다.

## KG이니시스

현재 랭크업 사이트 medihelpers.co.kr에서 사용 중인 계약/MID를 새 자체 개발 사이트에서 계속 사용하려고 합니다. 동일 사업자·동일 대표 도메인 유지 예정입니다. 아래 확인 부탁드립니다.

- 현 계약이 독립 가맹점인지 호스팅형인지, 랭크업 외 신규 연동에서도 기존 MID를 유지할 수 있는지
- 현재 PC/모바일 결제 모듈 및 신규 웹표준/PRO 연동 가능 여부, 필요한 신청·심사·비용
- www/apex 도메인·return/close/noti URL·서버 IP 등록/변경 요건
- PC signKey와 취소/조회 API 자격정보 발급 방법, 발급·재발급 시 구 사이트 영향
- 카드/계좌이체/가상계좌/간편결제 중 계약된 수단 및 부분취소 지원
- 테스트 MID/시나리오, 운영 전환 검수와 소액 승인·취소 절차
- 구 TID의 취소·부분환불·거래조회 유지, 미입금 가상계좌/진행 거래의 통보 수신 전환
- 승인 후 통신/DB 장애 시 망취소, 결과 불명 상태의 거래조회/대사 권장 절차

키 원문은 가맹점관리자의 보안 경로에서 확인하겠습니다.
