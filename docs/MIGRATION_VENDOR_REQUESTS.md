# 랭크업·이니시스 확인 요청 초안

아래는 사용자 검토용 초안이며 업체에 발송하지 않았습니다. 비밀번호나 키를 일반 메일/채팅으로 요청하지 않습니다.

## 랭크업

medihelpers.co.kr을 새 시스템으로 이전하려고 합니다. 기존 회원을 최대한 유지하고 공고·이력서·결제 및 잔여 유료 권리를 검증해 이전할 예정입니다. 아래 제공 범위와 방법·비용·소요기간을 확인 부탁드립니다.

- 전체 DB 백업(SQL), DB 버전/문자셋/타임존, 테이블·컬럼/회원등급/상태 코드 설명
- 회원 아이디·회원번호·이메일·연락처·병원정보·가입/탈퇴/정지 상태 및 약관/공개/마케팅 동의 증거
- 비밀번호 저장 알고리즘, salt/반복수/인코딩 설명(평문 비밀번호 불필요)
- 공고·이력서·지원·첨부파일 전체 백업과 원래 URL/소유 회원번호 매핑
- 주문·이니시스 TID·승인/취소/환불·미결제 내역, 상품별 만료일/잔여 횟수/열람 권리
- 백업 기준 시각·테이블별 건수·파일 목록/체크섬, 최종 증분 추출 방법
- 쓰기/결제 일시 중지, 이전 후 기존 관리자 조회·과거 거래 환불 유지, 호스팅 종료 시점
- DNS/도메인 관리 주체와 전체 레코드 백업, 기존 메일 유지 방법
- 부동산/게시판 등 새 사이트에 없는 자료의 백업 범위

원본 자료는 접근 제한 다운로드 또는 암호화 전달 방식으로 부탁드립니다.

## KG이니시스

현재 랭크업 사이트 medihelpers.co.kr에서 사용 중인 계약/MID를 새 자체 개발 사이트에서 계속 사용하려고 합니다. 동일 사업자·동일 대표 도메인 유지 예정입니다. 아래 확인 부탁드립니다.

- 현 계약이 독립 가맹점인지 호스팅형인지, 랭크업 외 신규 연동에서도 기존 MID를 유지할 수 있는지
- 현재 PC/모바일 결제 모듈 및 신규 웹표준/PRO 연동 가능 여부, 필요한 신청·심사·비용
- www/apex 도메인·return/close/noti URL·서버 IP 등록/변경 요건
- PC signKey와 취소/조회 API 자격정보 발급 방법, 발급·재발급 시 구 사이트 영향
- 카드/계좌이체/가상계좌/간편결제 중 계약된 수단 및 부분취소 지원
- 테스트 MID/시나리오, 운영 전환 검수와 소액 승인·취소 절차
- 구 TID의 취소·부분환불·거래조회 유지, 미입금 가상계좌/진행 거래의 통보 수신 전환
- 승인 후 통신/DB 장애 시 망취소, 결과 불명 상태의 거래조회/대사 권장 절차

키 원문은 가맹점관리자의 보안 경로에서 확인하겠습니다.
