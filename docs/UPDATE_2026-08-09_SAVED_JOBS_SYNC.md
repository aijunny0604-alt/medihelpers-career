# 관심 공고 표시 정리 및 계정 동기화

## 카드 표시

- 채용공고 카드의 `AD · 병원 브랜드 광고`, `DEMO · 가상 공고` 문구를 제거했습니다.
- 카드 배너 아래의 `병원 브랜드 채용관`, `광고 디자인 예시 · 공식 로고 아님` 보조 문구를 제거했습니다.
- 공고 상세의 `AD · 병원 브랜드 채용관` 문구도 제거했습니다.
- 광고 등급을 구분하는 `집중채용` 등의 핵심 태그와 하트 버튼은 유지합니다.

## 관심 공고 저장

- 비로그인 사용자의 찜은 해당 브라우저에 임시 저장됩니다.
- 로그인 회원의 찜은 D1의 `saved_jobs`에 계정 기준으로 저장됩니다.
- 메인, 병원채용 목록, 공고 상세 진입 시 로그인 계정의 서버 찜 목록을 불러옵니다.
- 다른 PC에서 같은 계정으로 로그인해도 동일한 하트 상태가 표시됩니다.
- 서버 응답의 최종 저장 여부로 화면 상태를 다시 맞춰 빠른 연속 조작에서도 어긋나지 않게 합니다.
