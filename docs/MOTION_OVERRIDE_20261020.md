# 사이트 모션 항상 활성화

2026-10-20 사용자 요청에 따라 시스템의 ‘동작 줄이기’, CPU·메모리 감지, 데이터 절약·저속망 설정 때문에 기존 모션이 중단되지 않도록 변경했다. 기존 랭크업은 유지하고 별도 QA 사이트에만 반영한다.

- 초기화 시 `force-motion`을 적용하고 `performance-lite`를 제거한다.
- 모든 reduced-motion CSS가 명시적 모션 모드에서는 적용되지 않도록 통일했다.
- 설정과 무관하게 화면 전환을 막던 전역 CSS를 정리했다.
- 모바일 도우미 애니메이션과 가입 완료 장식을 복구했다.
- 공고 상세의 고정 지원 영역과 목록 스크롤 위치 복원은 유지했다. 이를 깨뜨리던 오래된 강제 화면 전환 덮어쓰기 규칙도 제거했다.
- 광고를 읽거나 키보드로 조작할 때, 화면 밖이나 비활성 탭에서는 일시정지를 유지한다.
- 메인 영상은 기존 무음 자동재생·반복재생·사용자 동작/탭 복귀 재시도를 유지한다. 브라우저 자체의 자동재생 차단이나 숨긴 탭의 실행 제한을 우회하지 않는다.

## 검증

단위 **577개**, 격리 런타임 **2,346개**, 합계 **2,923개 통과**. 두 빌드와 diff 검사 통과. 신규 회귀 검사는 환경 조건 32조합, 모든 reduced-motion CSS의 예외 처리, 상세 고정 영역, 모바일·가입 완료 장식을 포함한다.

실제 브라우저의 `prefers-reduced-motion: reduce`가 **true**인 상태에서 로컬 예시 화면을 검수했다.

| 항목 | 결과 |
| --- | --- |
| 루트 모션 상태 | `force-motion`, `data-performance=full` |
| 화면 전환 | `route-stage-enter` 적용 |
| 도우미 | `medi-angel-float`, 시간에 따라 transform 값 변경 |
| 모바일 390×844 | 도우미 모션 유지, 가로 넘침 없음 |
| 진료과 선택창 | `select-menu-in`, 0.22초 |
| 메인 영상 | paused=false, 재생 시간 진행 확인 |
| 광고 캐러셀 | 자동 순환 표시 및 다음 묶음 전환 확인, 조작 시 일시정지 |

일반 모션 설정은 자동 검사에서 확인했으며 OS 설정을 변경한 두 번째 실제 브라우저 실행은 수행하지 않았다. 실제 모바일 기기·다른 브라우저 전수 검증은 아니다. 테스트 사이트는 공개 공고가 없어 광고 검수는 로컬 예시 데이터로 수행했다.
