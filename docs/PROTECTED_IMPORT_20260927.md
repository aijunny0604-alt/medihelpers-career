**보호 반입은 회원 로그인 활성화와 다르다.** 원본 회원 상태와 비밀번호 후보의 실제 로그인 검증이 없어 281계정은 `suspended`와 `MIGRATION_HOLD` 사유로 보류한다. 이는 원래 정지회원이라는 판정이 아니다. 공고는 계속 관리자 전용 초안이다. 알림·마케팅을 자동 동의 처리하지 않았고, 기존 유료 권리를 새로 지급하거나 결제 원장을 만들어 넣지 않았다. 원본 가입일은 미확인으로 명시하고 새 DB의 생성일은 반입 시각으로 기록했다.

## 결제 IP 안내 정정

[이니시스 공식 방화벽 안내](https://www.inicis.com/blog/archives/121212)는 가맹점 IP 별도 등록이 불필요하다고 설명한다. 따라서 ‘IP 등록이 필수이므로 Cloudflare에서 결제 불가능’이라고 단정하지 않는다.

다만 [공식 취소 API](https://manual.inicis.com/inipaypro/cancel.html)는 V1과 V2 모두 `clientIp`를 가맹점 요청 서버 IP 필수값으로 명시한다. Cloudflare의 요청 서버 식별 방식은 아직 확정하지 않았다. 임의로 기존 랭크업 IP나 방문자 IP를 대입해 환불 검증을 통과한 것으로 처리하지 않는다. 실제 MID의 거래 조회·승인·취소 검증은 별도로 남아 있다.
