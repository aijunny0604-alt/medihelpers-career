# 모바일 UX·UI 및 초기 로딩 검수 — 2026-09-13

## 판단

확인한 모바일 문제를 수정하고 주요 사용 흐름을 격리 환경에서 직접 검수했다. 브라우저 화면 크기 에뮬레이션이며 iPhone Safari·Android 실기기, 실제 모바일 키보드·카메라, 통신 지연·대규모 동시접속의 실측을 대체하지 않는다. 버그가 없다고 보증하거나 실PG 정식 출시가 완료됐다는 의미가 아니다.

## 수정 사항

- 홈이 고정 헤더 아래에서 시작하도록 정렬해 소개 문구 가림을 해결했다. 모바일 제목 줄바꿈·상하 여백을 조정했다.
- 휴대폰·태블릿(1024px 이하), 동작 줄이기, 데이터 절약 환경은 기존 70,073바이트 포스터를 표시한다. 모바일에서 4,090,915바이트 배경 영상의 source를 생성하지 않는다. 일반 데스크톱 영상은 유지한다.
- 관리자·마이페이지·가입·이력서·복구·의료인·법률 안내 등은 React lazy/Suspense로 필요할 때 불러온다. 공통 로그인 요청과 테스트 계정 정의는 accountApi.js로 옮겨 첫 화면에 가입 폼이 포함되지 않도록 했다. 인증 동작은 동일하다.
- Sites Worker가 Vite의 모든 JS/CSS 청크를 정확한 MIME·immutable 캐시로 제공하도록 패키징을 보완했다. 알려지지 않은 assets 경로는 HTML 대신 404, 내부 파일은 계속 비공개다.
- 화면 로딩 실패 시 메뉴를 유지하고 다시 불러오기 버튼을 제공한다. 오래된 배포 청크나 연결 실패에서 흰 화면에 갇히지 않는다.
- 모바일 입력 글자는 16px로 통일했다. 공고 등록란의 기존 15px도 포함한다.
- 모바일 도우미 크기를 80×94에서 58×68px로 줄이고 입력 중에는 숨긴다. 하단 여백과 팝업 폭·높이를 화면에 맞췄다.
- 이력서의 기타 직군을 선택하면 선택 표시가 초기값으로 돌아가는 오류를 수정했다. 선택 전에는 직접 입력란을 숨기고 기타 선택 상태를 별도로 유지한다.

## 성능 측정

전송 시간·Lighthouse 점수가 아닌 빌드 산출물 용량 비교다. 첫 HTML이 참조하는 엔트리와 공통 preload JS를 합산했다.

CSS는 기존 디자인 규칙을 유지해 용량을 크게 줄이지 않았다. 외부 글꼴·지도·이미지 전송 및 실기기 Web Vitals는 별도 측정 대상이다. 지연 로딩된 페이지도 방문하면 필요한 추가 JS가 전송된다.
