## 3. 🚨 R2 이미지 업로드는 Sites에서 동작하지 않음 (의도된 한계)

- 업로드 API(`/api/uploads`)는 R2 바인딩 `env.UPLOADS`를 사용한다.
- **`env.UPLOADS`는 Cloudflare 빌드(`build:cf`)의 `wrangler.toml`에만 있다. OpenAI Sites에는 R2가 없다.**
- 따라서 Sites에서 이미지 업로드 시 **HTTP 503 "이미지 업로드 저장소가 설정되지 않았습니다"** 로 안전하게 실패한다(크래시 아님, UI는 에러 문구 표시).
- **활성화 조건(Cloudflare 이전 후):**
  1. `wrangler r2 bucket create medihelpers-uploads`
  2. `build:cf`로 배포(wrangler.toml에 `[[r2_buckets]] binding=UPLOADS` 이미 포함)
  3. 업로드 이미지는 `/api/uploads/<key>`로 서빙됨(공개 읽기, sandbox CSP)
- **남은 보안 작업:** 업로드 파일 악성코드 검사(현재 미구현, 타입·5MB 제한만). 출시 차단 조건.

## 4. Sites 배포 후 검증 체크리스트

- [ ] **다른 PC/폰에서 같은 계정 로그인** — 회원가입(PC1) → 다른 기기 로그인(PC2) → 마이페이지·찜 동기화 확인
- [ ] **공고 등록 → 승인 → 공개**: /admin/post에서 게시 → /jobs 노출 / 병원 광고 draft → 관리자 콘솔 승인 → 공개
- [ ] **결제(테스트 모드)**: 주문 생성 → 승인 → 마이페이지 결제이력 표시(실결제 아님)
- [ ] **관심공고 하트**: 한 기기에서 찜 → 다른 기기 /jobs 카드 하트에도 채워짐
- [ ] **히어로 영상**: '동작 줄이기' 켠 기기에서도 재생
- [ ] **모바일 메뉴**: 햄버거 → 딤 + 배경 스크롤 잠금 + 바깥 클릭 닫힘
- [ ] **이미지 업로드**: /admin/post 업로드 시 **503 예상(정상 — Cloudflare 전까지)**

## 5. 실서비스(결제·업로드)까지 남은 최종 관문

| 항목 | 현재 | 활성화 조건 |
|---|---|---|
| 실결제 | 이니시스 연동 코드 완료, 테스트(가상) 결제만 | `INICIS_MID`/`INICIS_SIGN_KEY`/`SITE_ORIGIN` 설정 + 웹훅 + **Cloudflare 이전**(Sites는 약관상 PCI 금지) |
| 이미지 업로드 | 코드 완료, Sites는 R2 없어 503 | Cloudflare 이전 + `medihelpers-uploads` 버킷 생성 |
| 알림(메일·문자) | 코드 완료 | Resend/Solapi 키 환경변수 |
| 악성파일 검사 | 미구현 | 업로드 스캔 추가(출시 차단) |

→ **결제·업로드는 Cloudflare 이전이 공통 관문.** `docs/CLOUDFLARE_MIGRATION.md` 참고.
